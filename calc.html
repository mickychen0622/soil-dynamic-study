Q2

Machine foundation SDOF: ωn, ξ, ωd, δ機器基礎 SDOF

2025 Midterm · 20 pts
A foundation–machine system is modeled as an SDOF system with W = 1000 kN, k = 200,000 kN/m and c = 2340 kN·s/m. Determine (a) the natural circular frequency ωn, (b) the damping ratio ξ, (c) the damped circular frequency ωd and (d) the logarithmic decrement δ (5 pts each).基礎加機器重 1000 kN、彈簧 200,000 kN/m、阻尼器 2340 kN·s/m，求自然圓頻率、阻尼比、阻尼圓頻率、對數遞減。
Solution · 完整作答

Given W = 1000 kN, k = 200,000 kN/m, c = 2340 kN·s/m, g = 9.81 m/s²

(a) Natural circular frequency自然圓頻率§4.2
\[\begin{aligned} m &= \frac{W}{g} = \frac{1000\ \text{kN}}{9.81\ \text{m/s}^2} = 101.94\ \text{t} \\ \omega_n &= \sqrt{\frac{k}{m}} = \sqrt{\frac{200{,}000}{101.94}} = \boxed{44.29\ \text{rad/s}} \end{aligned}\]
(b) Damping ratio阻尼比§4.3
\[\begin{aligned} c_c &= 2m\omega_n = 2(101.94)(44.29) = 9030\ \text{kN}\cdot\text{s/m} \\ \xi &= \frac{c}{c_c} = \frac{2340}{9030} = \boxed{0.259} \end{aligned}\]
(c) Damped circular frequency阻尼圓頻率§4.3
\[\omega_d = \omega_n\sqrt{1-\xi^2} = 44.29\sqrt{1-0.259^2} = \boxed{42.78\ \text{rad/s}}\]
(d) Logarithmic decrement對數遞減§4.9
\[\delta = \frac{2\pi\xi}{\sqrt{1-\xi^2}} = \frac{2\pi(0.259)}{\sqrt{1-0.259^2}} = \boxed{1.686}\]

Ans. ωn = 44.3 rad/s; ξ = 0.259; ωd = 42.8 rad/s; δ = 1.69

Q3

Undamped free vibration: phase angle and amplitude無阻尼自由振動

2025 Midterm · 10 pts
For the same system, the initial displacement and velocity are u(0) = 0.05 m and u̇(0) = 0.01 m/s. Ignoring damping, determine (a) the phase angle of the displacement and (b) the displacement amplitude (5 pts each).同一系統，初始位移 0.05 m、初速 0.01 m/s，不計阻尼，求相位角與位移振幅。
Solution · 完整作答

Given ωn = 44.29 rad/s (from Q2), u(0) = u0 = 0.05 m, u̇(0) = u̇0 = 0.01 m/s, damping ignored

Equation of motion無阻尼自由振動解§4.2
\[\begin{aligned} u(t) &= u_0\cos\omega_nt + \frac{\dot u_0}{\omega_n}\sin\omega_nt = \rho\sin(\omega_nt+\theta) \\ \frac{\dot u_0}{\omega_n} &= \frac{0.01}{44.29} = 2.258\times10^{-4}\ \text{m} \end{aligned}\]
(a) Phase angle相位角§4.2
\[\begin{aligned} \tan\theta &= \frac{u_0}{\dot u_0/\omega_n} = \frac{u_0\,\omega_n}{\dot u_0} = \frac{0.05(44.29)}{0.01} = 221.5 \\ \theta &= \tan^{-1}(221.5) = \boxed{89.74^\circ\ (1.566\ \text{rad})} \end{aligned}\]
(b) Displacement amplitude位移振幅§4.2
\[\rho = \sqrt{u_0^2 + \left(\frac{\dot u_0}{\omega_n}\right)^2} = \sqrt{0.05^2 + (2.258\times10^{-4})^2} = \boxed{0.0500\ \text{m}}\]

Ans. θ = 89.7° (for u = ρ sin(ωnt + θ)); ρ = 0.0500 m

Masing loops and damping ratioMasing 迴圈與阻尼比

Homework · key
Hyperbolic backbone with Gmax = 94,000 kPa and γref = 0.0004 (decimal); loading path 0 → γc → −γc → γc. (a) Loops and D = ED/(4πESo) for γc = 0.01 % and 0.1 %, compared with Q1. Solution · 完整作答

Given Gmax = 94,000 kPa, γref = 0.0004; γc = 0.0001 (0.01 %) and 0.001 (0.1 %); strains in decimal

\[f(\gamma) = \frac{G_{max}\gamma}{1+|\gamma|/\gamma_{ref}},\qquad \text{unloading: } \tau = \tau_c + 2f\!\left(\frac{\gamma-\gamma_c}{2}\right),\qquad \text{reloading: } \tau = -\tau_c + 2f\!\left(\frac{\gamma+\gamma_c}{2}\right)\]

\[\begin{aligned} \tau_c &= \frac{94{,}000(0.0001)}{1+0.25} = 7.52\ \text{kPa},\qquad E_{So} = \tfrac12\tau_c\gamma_c = \tfrac12(7.52)(0.0001) = 0.376\ \text{J/m}^3 \\ D &= \frac1\pi\left[4\left(1+\frac1x\right)\left(1-\frac{\ln(1+x)}{x}\right) - 2\right] = \frac1\pi\left[4(5)\left(1-\frac{\ln1.25}{0.25}\right) - 2\right] = \boxed{4.73\,\%} \\ E_D &= 4\pi E_{So}D = 4\pi(0.376)(0.0473) = 0.223\ \text{J/m}^3 \end{aligned}\]
