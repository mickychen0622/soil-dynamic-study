室內動態試驗

共振柱是一個會量阻尼的 SDOF。扭轉波動方程式給出頻率方程式 \(I/I_0 = \beta\tan\beta\)，由共振頻率得到 \(V_s\) 與 \(G\)，再用單元 4 的自由衰減與半功率法得到阻尼。各種試驗涵蓋不同的應變範圍，最後要把實驗室的曲線形狀和現地的 \(G_{max}\) 組合起來。

這個單元要回答

MRD 曲線是怎麼量出來的？實驗室的結果能直接用在現地嗎？

9.1

共振柱：儀器與頻率方程式

出處：Ch3 講義 3.2–3.13、4.2–4.9（投影片 p. 33–44）；郭安妮 Soil Properties Part 2 講義 p. 2–3；Richart et al. (1970) 書頁 72–73、301–307（PDF p. 93–94、322–328）

開場問題

\(10^{-4}\,\%\) 的剪應變，在 10 cm 高的試體上只對應數奈米的位移，位移計根本看不到。那要怎麼量 \(G\)？

答案：不量位移和力，改量頻率。頻率是最能精確量測的物理量之一；把試體激振到共振，反應最大、訊號最清楚，只需很小的扭矩。共振頻率由試體的勁度與慣性決定，反推就得到 \(V_s\) 與 \(G\)。

部件功能在理論中的角色
底座（含透水石）夾住試體底部、排水邊界條件 \(\theta(0,t) = 0\)：駐波的節點
試體實心圓柱（典型 D = 50 mm、h = 100 mm），施加圍壓\(\rho\)、\(G\)、\(J\)、\(h\)；質量極慣性矩 \(I = mD^2/8\)
頂蓋＋驅動板＋磁鐵＋加速度計隨試體頂部一起轉動剛體慣性 \(I_0\)，以已知 G、J 的金屬率定桿反推
驅動線圈（固定在框架）通交流電 → 磁鐵受力 → 諧和扭矩。四力同旋向 → 扭轉（量 G）；同平移向 → 撓曲（量 E）外加扭矩 \(T_0\cos\bar\omega t\)
加速度計、LVDT量頂蓋切向加速度；低頻轉角與試體沉陷找 \(f_n\)、換算應變；更新 \(h\)、\(\rho\)

一條方程式、兩個邊界條件

試體內部就是 3.2 的扭轉波動方程式 \(\ddot\theta = V_s^2\theta''\)。底部固定 \(\theta(0,t) = 0\)。頂部：試體對驅動系統施加 \(-GJ\theta'(h)\)，驅動系統按牛頓第二定律轉動：

\[ -GJ\,\frac{\partial\theta}{\partial z}\bigg|_{z=h} = I_0\,\frac{\partial^2\theta}{\partial t^2}\bigg|_{z=h} \qquad\Longrightarrow\qquad \frac{I}{I_0} = \beta\tan\beta, \qquad \beta = \frac{\omega_n h}{V_s} \]
推導：分離變數與五步代數
  1. 自由振動：\(\theta = \Theta(z)\cos\omega_n t\)，代入波動方程式得 \(\Theta = C_3\cos kz + C_4\sin kz\)，\(k = \omega_n/V_s\)。底部 \(\Theta(0) = 0\) → \(C_3 = 0\)。
  2. 頂部：\(-GJC_4k\cos kh = -I_0\omega_n^2C_4\sin kh\)。要非零解，\(C_4\) 消去：\(GJk\cos kh = I_0\omega_n^2\sin kh\)。
  3. 用 \(\omega_n = kV_s\)、\(G = \rho V_s^2\)：\(\rho V_s^2Jk\cos kh = I_0k^2V_s^2\sin kh\) → \(\rho J = I_0k\tan kh\)。
  4. 兩邊乘上 \(h\)，並用 \(I = \rho Jh\)（試體＝一疊薄圓盤，每片轉動慣量 \(\rho J\,dz\)）：\(I = I_0(kh)\tan(kh)\)。
  5. 令 \(\beta = kh = \omega_nh/V_s = 2\pi h/\lambda\)：\(I/I_0 = \beta\tan\beta\)。模態形狀 \(\Theta(z)/\Theta(h) = \sin(\beta z/h)/\sin\beta\)。

符號檢查：頂部比下方扭得多 → \(\theta'(h) > 0\) → 試體把驅動系統往回拉 → 角加速度為負，第一式的負號正是如此。

資料處理順序：量 \(f_n\) → 算 \(I = mD^2/8\) → 取 \(I_0\)（率定）→ 解 \(\beta\tan\beta = I/I_0\) → \(V_s = 2\pi f_nh/\beta\) → \(G = \rho V_s^2\)。\(\beta\tan\beta = I/I_0\) 沒有封閉解，查表或幾行數值解。

兩個極限與 1/3 法則

極限 1：頂部自由極限 2：驅動系統慣性主導（本儀器）
條件\(I/I_0 \to \infty\)（\(I_0 \to 0\)）\(I/I_0 \ll 1\)
\(\beta\)\(\to \pi/2\)\(\approx \sqrt{I/I_0}\)
共振頻率\(f_n = V_s/4h\)\(\omega_n^2 = (GJ/h)/I_0 = k/m\)
試體占的波長\(h = \lambda/4\)\(h/\lambda = \beta/2\pi \approx 0.04\)
扭轉沿高度四分之一正弦近乎線性
對應岩盤上土層的基本共振（單元 10）SDOF：扭轉彈簧＋頂部質量（單元 4）

把 \(\tan\beta = \beta + \beta^3/3 + \dots\) 多保留一項：\(\beta^2 \approx (I/I_0)/(1 + I/3I_0)\)，也就是 \(\omega_n^2 = (GJ/h)/(I_0 + I/3)\)。有分布慣性的彈簧 ≈ 無質量彈簧＋三分之一自身慣性加到端點。\(I/I_0 = 0.056\)：SDOF 給 0.2366、1/3 修正 0.2345、精確 0.2345。

由加速度換算剪應變

加速度計裝在頂蓋半徑 \(r\) 處，量切向加速度 \(a\)：頂部轉角 \(\theta_h = a/(r\omega^2)\)。實心圓柱扭轉時，剪應變在軸心為 0、表面最大，所以要約定一個代表半徑：

\[ \gamma = \frac{r_{eq}\,\theta_h}{h}, \qquad r_{eq} \approx 0.8R \]

面積平均半徑是 \(2R/3\)；扭矩加權平均是 \(4R/5\)，給應變較大的外圈較多權重，共振柱實務與虛擬實驗都用 0.8R。報告的 \(\gamma\) 是代表值，實際應變在斷面上從 0 變到 \(R\theta_h/h\)。大應變研究為了讓應變更均勻，Drnevich (1967) 改用空心試體（Richart et al. 書頁 307）。

例：DEM 虛擬共振柱（D = 29.92 mm、h = 61.21 mm、m = 60 g、I₀ = 1.2×10⁻⁴ kg·m²）

\(I = 0.06\times0.02992^2/8 = 6.71\times10^{-6}\)，\(I/I_0 = 0.056\)，\(\beta = 0.2344\)；\(f_n\) = 190.15 Hz → \(V_s = 2\pi\times190.15\times0.06121/0.2344 = 312.0\) m/s；\(\rho = 1394\) kg/m³ → \(G = 135.8\) MPa（率定值 135.8 MPa）。加速度 0.314 m/s²、\(r\) = 15 mm：\(\theta_h = 0.314/(0.015\times(2\pi\times190.15)^2) = 1.47\times10^{-5}\) rad，\(\gamma = 0.8\times0.01496\times1.47\times10^{-5}/0.06121 = 2.9\times10^{-6}\)（= 2.9×10⁻⁴ %）。

投影片勘誤：頂部扭矩寫法

投影片 p. 39–40 把彈性扭矩寫成 \(T = G(I/\rho)\,\partial\theta/\partial z\)、慣性扭矩寫成 \(-I_0h\,\ddot\theta\)。因為 \(I = \rho Jh\)，正確是 \(GJ = GI/(\rho h)\)：前式少了 \(1/h\)，後式多乘了 \(h\)，兩者剛好抵銷，最後的 \(I/I_0 = \beta\tan\beta\) 正確。建議直接寫 \(GJ\) 和 \(-I_0\ddot\theta\)。投影片 p. 44 的橫軸 \(I_\theta/I_t\) 就是 \(I/I_0\)（試體／驅動系統）。

9.2

共振柱：掃頻、阻尼與大應變

出處：Ch3 講義 3.14–3.19、4.10–4.17（投影片 p. 45–50）；郭安妮 Soil Properties Part 2 講義 p. 4；Richart et al. (1970) 書頁 306–307

開場問題

加大扭矩重做共振柱，得到的阻尼比還能相信嗎？兩種量阻尼的方法，誰會先失效？

找共振：兩階段掃頻

小應變時土壤阻尼很小，共振峰很尖：半功率頻寬 \(\Delta f = 2Df_n\)。D = 1.6 %、\(f_n\) = 25 Hz 時頻寬只有 0.8 Hz。所以 GDS 的做法是：① 粗掃（例如 5–35 Hz、每 5 Hz）找到大概位置；② 在估計峰值 ±5 Hz 內細掃（每 0.1 Hz）。\(G \propto f_n^2\)，頻率誤差 1 % 就是 \(G\) 誤差 2 %。

更精確的方法是看相位：共振時位移落後扭矩 90°，也就是扭矩與速度同相。把兩個訊號接到示波器的 x–y 輸入，同相時畫出一條直線、偏離時變成橢圓；這比找振幅峰值精確得多（Richart et al. 書頁 306–307；原理見 4.5）。

量阻尼的兩種方法

\[ \text{自由衰減：}\ \delta = \frac{1}{n}\ln\frac{X_1}{X_{n+1}},\quad D = \frac{\delta}{\sqrt{4\pi^2+\delta^2}} \approx \frac{\delta}{2\pi} \qquad\qquad \text{半功率：}\ D \approx \frac{f_2 - f_1}{2f_n} \]

自由衰減：在共振頻率激振、關掉驅動、記錄頂蓋的衰減振動，把 ln(峰值) 對週期數畫直線，斜率就是 \(-\delta\)。點不成直線，本身就說明阻尼與振幅有關。半功率：在掃頻曲線上找振幅降到峰值 \(1/\sqrt2\) 的兩個頻率。兩者的推導與誤差分析見 4.9。

推導：共振柱的半功率公式從哪裡來
  1. 穩態諧和運動用複數模數 \(G^* = G(1 + 2iD)\)：應力領先應變一個小角，\(\tan = 2D\)；每週期消散能量 ÷（4π × 峰值彈性能）恰為 \(D\)。
  2. 外加扭矩 \(T_0e^{i\bar\omega t}\)，內部 \(\Theta = C\sin k^*z\)，\(k^* = \bar\omega\sqrt{\rho/G^*}\)。頂部條件給 \(\Theta(h) = T_0/(G^*Jk^*\cot k^*h - I_0\bar\omega^2)\)。無阻尼時分母在 \(GJk\cot kh = I_0\omega^2\) 為零，正是頻率方程式。
  3. \(\beta\) 小時用 \(\cot x \approx 1/x - x/3\)：反應化為 \((T_0/K_T)/\big[(1-r^2) + 2iD\big]\)，\(K_T = GJ/h\)、\(r = \bar\omega/\omega_n\)，\(\omega_n^2 = K_T/(I_0 + I/3)\)。
  4. 峰值 \((T_0/K_T)/2D\) 在 \(r = 1\)；半功率點 \((1-r^2)^2 = 4D^2\) → \(r_{1,2} \approx 1 \mp D\) → \(D = (f_2-f_1)/2f_n\)。

隱含假設：SDOF、線性、阻尼與頻率及振幅無關。大應變時後兩項失效。

大扭矩：曲線傾斜、跳躍，半功率法高估阻尼

土壤越搖越軟。掃頻時振幅不固定：遠離共振時小、接近共振時大，所以接近峰值時試體軟化、共振頻率往下移，曲線向低頻傾斜；往上掃時會在折疊處突然跳升。曲線的寬度同時反映了勁度與阻尼的振幅相依性，公式卻全部歸給阻尼，於是 \(D\) 被高估。公式沒有錯，是用在推導假設之外。自由衰減避開了掃頻：帶到指定振幅後釋放，在該振幅附近的前幾個週期評估衰減率。

系統阻尼、應變曲線與現地比較

兩種方法量到的都是試體＋儀器的總阻尼。儀器阻尼主要來自驅動線圈的反電動勢（back EMF，像煞車），要率定扣除；小應變時兩法應該接近，差很多時先懷疑儀器阻尼或程序。在各扭矩等級重複，就得到 \(G\) 與 \(D\) 隨應變的變化：本實驗室資料（圍壓 50–400 kPa）顯示 \(G_{max}\) 約隨 \(\sqrt{\sigma'}\) 增加；\(\gamma > 10^{-3}\,\%\) 後 \(G\) 下降、\(10^{-1}\,\%\) 時損失一半以上；圍壓越高越晚下降、阻尼越低。兩個門檻：線性門檻約 \(10^{-3}\,\%\)，體積門檻約 \(10^{-2}\,\%\)（以上反覆載重會產生體積變化或孔隙水壓）。完整的 MRD 曲線在單元 8，六個階段的資料處理見 HW3 Q1(b)。

投影片勘誤與常見錯誤

① 投影片 p. 47 寫 \(\delta = 2\pi D/\sqrt{1-D^2} = 2\pi D\)，後一個等號應為「≈」；投影片的 \(D\) 與 \(\xi\) 同義。② 投影片 p. 49 右圖縱軸標 \(G/G_{max}\)（MPa），\(G/G_{max}\) 無因次。③ 學生講義 3.14 說「小應變阻尼約 0.6 %，半功率寬約 2 Hz（\(2Df_n\)）」：\(2\times0.006\times25 = 0.3\) Hz，不是 2 Hz；結論（細掃要 0.1 Hz）不變，反而更必要。

小測驗

Δf = 2Dfn = 2 × 0.016 × 25 = 0.8 Hz。5 Hz 一格的粗掃完全可能錯過整個峰。
課後問題
共振柱在大應變時，為什麼半功率頻寬法會高估阻尼比？
半功率公式假設線性、阻尼與振幅無關。大應變時共振頻率隨振幅下降，曲線折疊變寬，量到的「頻寬」大部分來自軟化而不是能量消散。上方「大應變」分頁比較同一應變下的真實 D 與半功率 D 就能看到差距。
9.3

實驗室試驗與它們的應變範圍

出處：學生整理投影片 3.7–3.17、備註 4.2–4.17；老師講義 p. 30–40、44–58；郭老師 Soil Property Determination Part 2 p. 1–4、Dynamic Soil Behavior p. 4–8

開場問題

只做反覆三軸試驗，能得到完整的 MRD 曲線嗎？

不能。每種試驗只涵蓋一段應變：現地震測與彎曲元件在 \(\gamma_{tl}\) 以下，給 \(G_{max}\)；共振柱約 10⁻⁴–10⁻¹ %，正是曲線開始下降的範圍；反覆扭剪到約 1 %；反覆三軸與單剪約 10⁻² % 到數 %，給大應變的 \(G/G_{max}\)、阻尼與孔隙水壓反應。沒有單一試驗能涵蓋整條曲線，所以試驗要組合使用，重疊的範圍互相比對；重疊處差很多，通常是試體或量測有問題。

共振柱試驗（RCT）

把土柱激振到共振：量共振頻率 → 解頻率方程式 \(I/I_0 = \beta\tan\beta\)（\(\beta = \omega_nH/V_s\)）→ \(V_s\) → \(G = \rho V_s^2\)；關掉驅動記錄自由衰減 → 對數遞減 → 阻尼比。逐步加大驅動振幅，就描出 MRD 曲線的前段。理論推導、驅動系統與率定在 9.1、9.2；這裡只提醒四件事：

  1. 實心試體的剪應變由中心到外緣線性增加，報告的應變取等效半徑處，常用 ⅔–⅘ 半徑。
  2. 由小到大加振幅：大應變的擾動會影響之後的小應變結果。
  3. 自由衰減量到的是一段應變範圍的平均，且包含儀器本身的阻尼；阻尼大於約 10 % 時幾圈就消失，半功率頻寬法通常較可靠（4.9）。
  4. 頻率遠高於地震，對有速率效應的黏土要考慮。

彎曲元件

兩片壓電陶瓷黏合，加電壓時彎曲，尖端帶動土粒左右運動，產生沿試體上下傳播的剪力波：\(V_s = L/t\)。L 是兩元件尖端之間的距離，不是試體高度。驅動頻率數 kHz，波長只有數公分，與試體尺寸相當，會有近場效應；到時判讀（第一個明顯反轉、峰對峰、互相關）可以差約 10 %，報告要說明用哪一種。

反覆三軸與反覆單剪

\[ \text{cyclic triaxial:}\quad \tau = \frac{\sigma_d}{2}, \qquad \gamma = (1+\nu)\,\varepsilon_a = 1.5\,\varepsilon_a\ \ (\text{undrained},\ \nu = 0.5) \]

反覆三軸的主應力每半圈旋轉 90°，與垂直剪力波下的現地狀態不同（Ch8 用修正係數處理）；但台灣的液化試驗資料大多來自它。反覆單剪直接施加 \(\tau\)、量 \(\gamma\)，應力路徑最接近 5.1 的土壤元素；缺點是側面沒有互補剪應力，應力不均勻。定體積單剪固定試體高度，垂直應力的下降就等於不排水試驗中孔隙水壓的上升，不需要反水壓飽和，液化研究很常用。所有實驗室試驗都受取樣擾動、老化消失、組構破壞影響。

資料品質：投影片 4.10–4.11（講義 p. 52–53）的兩張圖

單位：G 軸標「MPa」但數值到 500 000，若真是 MPa 對砂大得不合理（5.9 的數量級），較可能是 kPa（約 50–130 MPa）。G/Gmax 圖是錯的：值在 0.2 以下甚至有負值，橫軸還是線性刻度、擠在 0.002 % 附近。正確的 MRD 圖要用對數應變軸，且小應變端應接近 1；這種結果通常是 \(G_{max}\) 取錯（例如取了最大的離群值）或正規化出錯。150 kPa 那組點在小應變沒有水平段，也不宜直接定 \(G_{max}\)。互動圖第三個分頁用合成資料重現這兩種錯誤。

9.4

由實驗室到現地性質

出處：學生整理投影片 3.18；老師講義 p. 41；郭老師 Dynamic Soil Behavior p. 19–23

開場問題

同一層砂，現地下孔試驗的 \(G_{max}\) 比實驗室共振柱高 50 %。場址反應分析該用哪一個？

兩個都用，但用在不同地方。這是目前場址反應分析的標準程序：

\[ G_{field}(\gamma) = \left(\frac{G}{G_{max}}\right)_{lab}(\gamma)\cdot\rho\,V_{s,field}^2, \qquad D_{field}(\gamma) \approx D_{lab}(\gamma) \]
  • 勁度水準取自現地：現地 \(V_s\) 保有年代、膠結與真實應力狀態。郭老師講義整理的經驗是 \(V_{s,field} > V_{s,lab}\)，原因是取樣擾動（對模數的影響遠大於對強度）、現地量測應變更小、長期載重效應（每個 log cycle 的時間都會增加 \(G_{max}\)）。
  • 曲線形狀取自實驗室或模型：正規化後的形狀受擾動影響較小。
  • 阻尼直接取實驗室值：現地沒有可靠方法量大應變阻尼；實驗室只量到材料阻尼，不含散射等機制。
  • 組合出的應力應變曲線在大應變隱含了一個剪力強度，要檢核是否合理（11.2）。
例

現地 \(V_s = 200\) m/s、\(\rho = 1.9\) t/m³ → \(G_{max} = 76\) MPa。實驗室在 \(\gamma = 0.05\%\) 得 \(G/G_{max} = 0.6\) → 現地該應變的 \(G = 0.6 \times 76 = 45.6\) MPa。這組 \(G_{max}\)、\(G/G_{max}\)、\(D\) 就是單元 11 等值線性分析的輸入。

常見陷阱：隱含的假設

這個做法假設現地曲線的形狀與實驗室試體相同。對老的或膠結的土壤，現地曲線可能比實驗室更線性，實驗室曲線會高估非線性。另外，只用實驗室 \(G_{max}\) 乘曲線，會把整條 \(G\) 曲線一起低估（HW3 Q3 約低三分之一）。

小測驗
現地 Vs = 250 m/s、ρ = 2.0 t/m³，實驗室在有效應變處 G/Gmax = 0.5、D = 9 %。等值線性輸入應為？
Gmax = 2.0 × 250² = 125 000 kPa = 125 MPa；G = 0.5 × 125 = 62.5 MPa。阻尼直接取實驗室值 9 %，不要乘或除 G/Gmax。

常見陷阱

  • J 與 I：J（m⁴）是斷面極二次矩，I（kg·m²）是質量極慣性矩；\(I = \rho Jh\)。投影片 p. 39–40 的 GI/ρ 應為 GJ。
  • δ = 2πD 要寫 ≈：精確式是 \(D = \delta/\sqrt{4\pi^2+\delta^2}\)（投影片 p. 47）。
  • 大應變不要用半功率法：曲線傾斜跳躍，D 可被高估一倍以上；改用自由衰減。
  • 室內與現地 Gmax 不同：取樣擾動、應力狀態、尺度；Gmax 取現地、曲線形狀取室內。

自我檢測

綜合題 1
共振柱試體 ρ = 2.0 Mg/m³、h = 0.1 m，I/I₀ = 0.0568（β = 0.2361），量到 fn = 60 Hz。G 約為幾 MPa？
Vs = 2π × 60 × 0.1 / 0.2361 = 159.7 m/s；G = 2.0 × 159.7² = 51.0 MPa（用 ρ = 2.04 則 52 MPa）。兩者都在答案的容許範圍內。
綜合題 2
一個場址 MASW 得到 Gmax = 80 MPa，同深度取樣做共振柱只得到 55 MPa。最合理的做法是？
取樣擾動通常讓室內 Gmax 偏低，現地方法保留了原位的應力狀態與結構。實務上 Gmax 取現地，曲線形狀（隨應變如何下降）取室內，這正是 9.4 與單元 11 的用法。
綜合題 3
某工程只做了反覆三軸試驗（0.02 %–2 %）與 MASW。等值線性分析的輸入還缺什麼最關鍵？
MASW 給現地 Vs → Gmax，水準有了。但反覆三軸在 0.01 % 以下沒有資料，曲線前段（剛開始下降的地方）只能外插，且三軸試體的 Gmax 也無法和現地值銜接。加做彎曲元件（同一試體）或共振柱補上小到中應變。
