階段 2 振動與頻率 · 單元 4 · Single-Degree-of-Freedom Vibration

單自由度振動

一個質量、一根彈簧、一個阻尼器。共振柱、場址放大、機器基礎與隔震，全部都用這套語言描述：系統有自己的自然頻率和阻尼比，被搖動時，反應取決於「搖的頻率」和「自己的頻率」之比。

這個單元要回答

一個系統被搖動時，什麼決定它搖得多大？

讀完這個單元，你應該能夠

  1. 寫出 SDOF 的運動方程式，並說明自然頻率 \(\omega\) 與阻尼比 \(\xi\) 的物理意義
  2. 判斷次阻尼、臨界阻尼、超阻尼三種自由振動，並解出初始條件下的反應
  3. 由 \(\beta\) 和 \(\xi\) 求出穩態振幅 \(D\) 與相位落後 \(\varphi\)，並用旋轉向量和力多邊形解釋三個頻率區
  4. 說明共振為什麼需要時間累積，以及阻尼比的能量定義 \(\xi = W_D/4\pi W_S\)
  5. 用自由衰減、共振放大、半功率頻寬三種方法從實驗資料求阻尼比，並知道各自的弱點
  6. 用傳遞率設計隔振

4.1

一個質量、一根彈簧、一個阻尼器

出處：Ch4 講義 1.1–1.3

開場問題

共振柱裡高 10 cm 的土樣、60 m 深的軟弱土層、放在橡膠墊上的精密儀器，尺度差了上千倍，為什麼可以用同一條方程式描述？

因為它們都只有「一個主要的運動方式」。只要一個位移 \(u\) 就能描述整個系統的狀態，這樣的系統稱為單自由度系統（SDOF）。它由三個元件組成：質量 \(m\) 儲存動能、彈簧 \(k\) 儲存位能、阻尼器 \(c\) 把能量消散掉。

把慣性 \(m\ddot u\) 移到力的一側並加上負號（D'Alembert 原理），動力問題就變成一個「靜力平衡」：

\[ m\ddot u + c\dot u + k u = p(t) \]
項力配對的運動量物理角色
\(m\ddot u\)慣性力 \(f_I\)加速度抗拒速度改變
\(c\dot u\)阻尼力 \(f_D\)速度消散能量
\(k u\)彈簧力 \(f_S\)位移把系統拉回平衡

記住這個「力 ↔ 運動量」的配對：簡諧運動中，速度領先位移 90°、加速度領先 180°，這正是 4.4 旋轉向量圖和 4.6 力多邊形的來源。

線性帶來的超能力：疊加

\(m\)、\(c\)、\(k\) 是常數，\(u\) 只以一次方出現，所以方程式是線性的。若 \(u_1\) 是外力 \(p_1\) 的解、\(u_2\) 是 \(p_2\) 的解，則 \(u_1+u_2\) 是 \(p_1+p_2\) 的解。

為什麼整章只算正弦外力

任何不規則的載重（地震紀錄、機器振動）都能用 Fourier 轉換拆成許多頻率的正弦波。只要知道系統對「單一頻率」的反應，把各頻率的反應加回去，就是總反應。這正是 SHAKE 等頻率域地盤反應程式的做法：Fourier 分解 → 乘上轉換函數 → 加總（10.4）。

例：把一層土看成 SDOF

厚度 \(H\) 的均勻土層放在剛性岩盤上：\(m\) 是參與振動的土體質量，\(k\) 是土層的剪力勁度（每單位面積約 \(G/H\)）。之後會看到它的基本週期是 \(T = 4H/V_s\)（5.3、10.6）。

\(H = 60\) m、\(V_s = 200\) m/s → \(T = 4 \times 60 / 200 = 1.2\) s。若地震的主要週期接近 1.2 s，這層土就會明顯放大地表運動。

小測驗
土壤在大應變下勁度會隨應變變小（k 不再是常數）。這時疊加原理還成立嗎？
k = k(u) 讓 ku 不再是 u 的一次式，疊加原理失效。這就是單元 11 要用「等值線性」的原因：先猜一個應變對應的 G，做線性分析，再用算出的應變更新 G，反覆迭代到一致。真正的非線性分析則要在時間域逐步積分。
4.2

無阻尼自由振動

出處：Ch4 講義 1.4–1.7

開場問題

把質量拉開一段距離、給它一個初速後放手，之後的振幅和週期由什麼決定？

沒有外力（\(p=0\)）也沒有阻尼（\(c=0\)）時，方程式剩下 \(m\ddot u + ku = 0\)。猜 \(u = Ge^{\lambda t}\)：指數函數微分後和自己成正比，代入後每一項都帶有 \(Ge^{\lambda t}\)，消去後得到特徵方程式：

\[ m\lambda^2 + k = 0 \;\Rightarrow\; \lambda = \pm i\omega, \qquad \omega = \sqrt{k/m} \]

根是純虛數，代表系統以頻率 \(\omega\) 永遠振動。用 Euler 公式把複數解換成實數形式：

\[ u(t) = \frac{\dot u(0)}{\omega}\sin\omega t + u(0)\cos\omega t = \rho\cos(\omega t - \varphi) \] \[ \rho = \sqrt{\left(\frac{\dot u(0)}{\omega}\right)^2 + u(0)^2}, \qquad \tan\varphi = \frac{\dot u(0)}{\omega\,u(0)} \]
推導：把 A sin + B cos 合成一個 cos
  1. 設 \(u = \rho\cos(\omega t-\varphi) = \rho\cos\varphi\cos\omega t + \rho\sin\varphi\sin\omega t\)。
  2. 與 \(u = A\sin\omega t + B\cos\omega t\) 比較係數：\(\rho\cos\varphi = B\)、\(\rho\sin\varphi = A\)。
  3. 平方相加得 \(\rho = \sqrt{A^2+B^2}\)，相除得 \(\tan\varphi = A/B\)；象限由 A、B 的正負決定。
  4. 初始條件：\(t=0\) 時 \(u(0) = B\)，\(\dot u(0) = A\omega\)。

這個技巧在 4.4 強迫振動會再用一次。

結論很直接：週期只由系統決定（\(m\)、\(k\)），振幅只由初始條件決定（怎麼放手）。三個描述快慢的量要會互換：

\[ f = \frac{1}{T}, \qquad \omega = 2\pi f = \frac{2\pi}{T} \quad (\omega \text{ 的單位是 rad/s}) \]
例：2000 kg 的塊體

\(m = 2000\) kg、\(k = 800\) kN/m；拉右 10 mm 後以 0.3 m/s 向右放開。（上面互動圖的「講義例」按鈕就是這組數字。）

\(f\)、\(T\)\(20/2\pi\)；\(1/f\)3.18 Hz；0.314 s
\(\rho\)\(\sqrt{(0.3/20)^2 + 0.010^2}\)18.0 mm

小測驗
一層土的自然週期 T = 0.5 s，角頻率 ω 是多少 rad/s？
f = 1/T = 2 Hz，ω = 2πf = 12.57 rad/s。常見錯誤是把 ω 和 f 混用，差了 2π 倍。
4.3

有阻尼自由振動

出處：Ch4 講義 1.8–1.14

開場問題

真實的系統搖一搖都會停下來。阻尼越大，回到平衡就越快嗎？

加回阻尼，特徵方程式變成 \(m\lambda^2 + c\lambda + k = 0\)，用公式解：

\[ \lambda = -\frac{c}{2m} \pm \sqrt{\left(\frac{c}{2m}\right)^2 - \omega^2} \]

一切取決於根號內的正負。根號為零時的阻尼係數稱為臨界阻尼係數 \(c_c = 2m\omega = 2\sqrt{km}\)。用它把 \(c\) 無因次化，就是阻尼比：

\[ \xi = \frac{c}{c_c} = \frac{c}{2m\omega} \qquad\Rightarrow\qquad \ddot u + 2\xi\omega\dot u + \omega^2 u = \frac{p(t)}{m} \]

右邊這個寫法之後會一直用到（\(c/m = 2\xi\omega\)、\(k/m = \omega^2\)）。

情形條件根運動
次阻尼\(\xi < 1\)\(-\xi\omega \pm i\omega_D\)邊振動邊衰減，\(u = e^{-\xi\omega t}(A\sin\omega_D t + B\cos\omega_D t)\)
臨界阻尼\(\xi = 1\)\(-\omega\)（重根）不振動、最快回到平衡，\(u = (G_1 + G_2 t)e^{-\omega t}\)
超阻尼\(\xi > 1\)\(-\xi\omega \pm \hat\omega\)不振動、慢慢爬回，\(\hat\omega = \omega\sqrt{\xi^2-1}\)

次阻尼的阻尼頻率 \(\omega_D = \omega\sqrt{1-\xi^2}\)，常數為 \(B = u(0)\)、\(A = [\dot u(0) + \xi\omega u(0)]/\omega_D\)。

為什麼超阻尼反而比較慢

超阻尼的兩個根中，衰減較慢的那個決定回到平衡的速度：\(\lambda = -\omega(\xi - \sqrt{\xi^2-1})\)。取 \(\xi = 2\)：\(2 - \sqrt 3 = 0.27\)，它以 \(e^{-0.27\omega t}\) 衰減，而臨界阻尼以 \(e^{-\omega t}\) 衰減，慢了將近 4 倍。阻尼強到質量像被黏住，只能慢慢爬回來，就像閥門關得太緊的自動關門器。

土壤和結構落在哪裡？一般建築約 2–5 %，小應變的土壤約 1–3 %，強震大應變下的土壤約 15–25 %，都遠小於 1。所以這門課幾乎只處理次阻尼。

常見陷阱：ωD 和 ω 要分嗎？

\(\xi = 0.2\) 時 \(\sqrt{1-0.04} = 0.98\)，\(\omega_D\) 只比 \(\omega\) 低 2 %。要低 10 % 需要 \(\sqrt{1-\xi^2} = 0.9\)，也就是 \(\xi \approx 0.44\)，沒有土壤或一般結構接近這個值。工程上取 \(\omega_D \approx \omega\) 很安全；但推導阻尼量測公式時要保留，才知道近似從哪裡來。

小測驗
設計一個指針儀表，希望指針最快停在讀數上而且不要來回晃。阻尼比應該選多少？
臨界阻尼是「不振動」中回得最快的；超阻尼反而變慢，小阻尼則會來回晃很多次。實務上常選略低於臨界（0.6–0.7）：允許一點點超越，卻更早到達讀數附近。汽車懸吊則刻意選 0.2–0.4，在舒適與抓地之間折衷。
4.4

簡諧外力：穩態反應

出處：Ch4 講義 1.15–1.19、1.23

開場問題

用固定頻率一直推一個系統，它最後會怎麼動？跟外力同步嗎？

外力 \(p(t) = p_0\sin\bar\omega t\)。注意 \(\bar\omega\)（上面有橫線）是外力頻率，由搖的人決定；\(\omega\) 是系統自己的自然頻率。完整解分成兩部分：

\[ u(t) = \underbrace{e^{-\xi\omega t}(A\sin\omega_D t + B\cos\omega_D t)}_{\text{暫態：以 } \omega_D \text{ 振動，會消失}} + \underbrace{\rho_s D\sin(\bar\omega t - \varphi)}_{\text{穩態：以 } \bar\omega \text{ 振動，一直存在}} \]

暫態幾個週期後就消失，剩下的穩態才是我們關心的。它只由兩個無因次量決定：

\[ \beta = \frac{\bar\omega}{\omega}, \qquad \rho_s = \frac{p_0}{k} \] \[ D = \frac{1}{\sqrt{(1-\beta^2)^2 + (2\xi\beta)^2}}, \qquad \tan\varphi = \frac{2\xi\beta}{1-\beta^2} \]

\(\rho_s\) 是外力慢慢加上去時彈簧的變位（靜態變位）。一句話：動態振幅是靜態變位的 \(D\) 倍，反應落後外力 \(\varphi\)。

推導：用複數三行完成
  1. 把外力寫成 \(p_0e^{i\bar\omega t}\) 的虛部，試 \(u_p = \mathrm{Im}(Ue^{i\bar\omega t})\)；每次微分就乘上 \(i\bar\omega\)。
  2. 代入 \(\ddot u + 2\xi\omega\dot u + \omega^2u = (p_0/m)e^{i\bar\omega t}\)，消去指數，除以 \(\omega^2\)： \[ U\left[(1-\beta^2) + i\,2\xi\beta\right] = \rho_s \]
  3. 分母的複數大小為 \(1/D\)、角度為 \(\varphi\)，除以它就是「長度乘 \(D\)、往回轉 \(\varphi\)」： \[ U = \rho_s D\, e^{-i\varphi} \;\Rightarrow\; u_p = \rho_s D\sin(\bar\omega t - \varphi) \]

這個複數乘上 \(k\) 就是動態勁度 \(k - m\bar\omega^2 + ic\bar\omega\)，在 4.10 的傳遞率和所有頻率域地盤反應程式中都會再出現。

若用實數法，要假設 \(u_p = G_1\sin\bar\omega t + G_2\cos\bar\omega t\)，sin 和 cos 項分別平衡，聯立解出 \(G_1 = \rho_s(1-\beta^2)D^2\)、\(G_2 = -\rho_s(2\xi\beta)D^2\)。cos 項一定要放，因為阻尼項的一次微分會把 sin 變成 cos；若 \(c=0\)，\(G_2 = 0\)，反應與外力同相或完全反相。

把穩態看成旋轉的三角形

穩態反應可以畫成一組以 \(\bar\omega\) 旋轉的向量：\(G_1\) 沿外力方向，\(G_2\) 落後 90°（只來自阻尼），兩者相加就是振幅 \(\rho_d = \rho_s D\)，固定落後外力 \(\varphi\)。整個三角形旋轉時形狀不變，所以振幅與相位落後都固定。實際的位移是向量在水平軸上的投影。

頻率區誰在扛外力\(\varphi\)行為
\(\beta \ll 1\)彈簧（勁度控制）≈ 0°質量跟著外力動，\(D \approx 1\)，就是靜載重
\(\beta = 1\)阻尼器（阻尼控制）90°\(G_1 = 0\)，振幅 \(\rho_s/2\xi\)，與 \(\xi\) 成反比
\(\beta \gg 1\)質量（慣性控制）≈ 180°質量跟不上變化太快的外力，幾乎不動
自己動手：橡皮筋掛重物

握住橡皮筋上端上下移動。很慢時，重物跟著手動；剛好在自然頻率時，振幅變得很大，而且重物落後手約四分之一週；動得很快時，重物幾乎停在空中不動。三個頻率區一次看完。

例：高架水塔在三種外力頻率下

水塔加水共 100 t，塔架側向勁度 4 MN/m，\(\xi = 0.05\)，受 20 kN 的簡諧側力。\(\omega = \sqrt{4\times10^6/10^5} = 6.32\) rad/s → \(f_n \approx 1\) Hz；\(\rho_s = 20\,000/(4\times10^6) = 5\) mm。

常見陷阱：計算機算 φ

小測驗
β = 2、ξ = 0.2 時，相位落後 φ 約為多少？
1 − β² = −3、2ξβ = 0.8。tan⁻¹(0.8/−3) 在計算機上會給 −15°，但分母為負，實際角度在第二象限：180° − 15° = 165°。β > 1 屬於慣性控制區，反應和外力幾乎反相。
4.5

頻率響應曲線：D–β 與 φ–β

出處：Ch4 講義 1.20–1.22、2.4

開場問題

只知道 β 和 ξ，不知道質量、勁度、外力大小，能預測放大多少倍嗎？

可以。\(D\) 和 \(\varphi\) 只取決於 \(\beta\) 與 \(\xi\)，與絕對大小無關。所以共振柱裡的小試體和 60 m 深的土層，只要 β、ξ 相同，就落在同一條曲線上。把這兩條曲線讀熟，就等於讀懂了所有線性振動問題。

曲線上要會讀的五件事

  1. \(\beta \to 0\)：\(D \to 1\)、\(\varphi \to 0\)。變化很慢的外力就是靜載重。
  2. 峰不在 \(\beta = 1\)，而在 \(\beta = \sqrt{1-2\xi^2}\)，高度 \(D_{max} = 1/(2\xi\sqrt{1-\xi^2})\)。\(\xi = 0.1\) 時峰在 0.99，高度只比 \(1/2\xi\) 大 0.5 %，所以實務上直接取「峰在 \(\beta = 1\)、高度 \(1/2\xi\)」。
  3. \(\xi \ge 0.707\) 沒有峰，曲線從 1 單調遞減，因為 \(1-2\xi^2 < 0\) 時根號不存在。
  4. \(\beta > \sqrt 2\) 時不論阻尼多少，\(D < 1\)（有阻尼時與 \(D=1\) 的交點在 \(\sqrt{2-4\xi^2}\)，稍早一點）。這預告了隔振。
  5. 所有有阻尼的 φ 曲線都在 \(\beta = 1\) 通過 90°。振幅峰會隨阻尼偏移，90° 的交點不會。無阻尼時是階梯：共振以下 0°、以上 180°。
推導：峰的位置與高度
  1. \(D\) 最大 ⇔ 根號內 \(g(\beta) = (1-\beta^2)^2 + 4\xi^2\beta^2\) 最小。
  2. \(g'(\beta) = -4\beta(1-\beta^2) + 8\xi^2\beta = 4\beta(\beta^2 - 1 + 2\xi^2) = 0\)。
  3. \(\beta = 0\) 是靜態端；另一根 \(\beta^2 = 1 - 2\xi^2\)。
  4. 代回：\(1-\beta^2 = 2\xi^2\)，\(g = 4\xi^4 + 4\xi^2(1-2\xi^2) = 4\xi^2(1-\xi^2)\)，所以 \(D_{max} = 1/(2\xi\sqrt{1-\xi^2})\)。
連到共振柱與場址放大

共振柱（單元 9）：同時記錄驅動電流與加速度計訊號，掃頻到「位移落後驅動 90°」的頻率就是共振頻率，不需要知道阻尼，也不需要量靜態變位。

場址放大（單元 10）：地震主要頻率接近土層自然頻率 \(V_s/4H\) 時 \(\beta \approx 1\)，地表運動放大數倍。真實土層還有高階模態（基頻的 3、5、7 倍），每個峰多高由阻尼決定。

小測驗
ξ = 0.05 的系統在 β = 1 受力，動態振幅是靜態變位的幾倍？
β = 1 時 D = 1/(2ξ) = 1/(2 × 0.05) = 10。阻尼比若降到 0.02，D 變 25；這就是為什麼共振時「阻尼比就是一切」。
4.6

力多邊形：誰在扛外力？

出處：Ch4 講義 2.2–2.3

把旋轉向量圖的每個長度乘上 \(k\)，位移就變成力。由 \(u = \rho_d\sin(\bar\omega t-\varphi)\) 出發，三個力的幅值以 \(p_0D\) 為單位是：

力幅值（以 \(p_0 D\) 為單位）方向
彈簧力 \(k u\)1沿位移方向
阻尼力 \(c\dot u\)\(c\bar\omega/k = 2\xi\beta\)領先位移 90°（與速度同相）
慣性力 \(m\ddot u\)\(m\bar\omega^2/k = \beta^2\)與位移反向

三個力頭尾相接，必須封閉在外力 \(p_0\) 上，這就是動力平衡。沿位移方向的合力是 \(p_0D(1-\beta^2)\)，垂直方向是 \(p_0D(2\xi\beta)\)，合起來長度剛好是 \(p_0D/D = p_0\)。

共振時只剩阻尼器在扛

\(\beta = 1\) 時慣性力與彈簧力等大反向、完全抵消，外力只能由阻尼力平衡，多邊形變成矩形：\(\rho_d = p_0/(c\bar\omega) = \rho_s/2\xi\)。這解釋了為什麼共振振幅只由阻尼決定。

設計問題
一座機器基礎在共振時振動過大。改 m、k、c 哪一個最直接降低「共振時」的振幅？
共振時外力只由阻尼器平衡，振幅 ρd = p0/(cω̄) 由 c 決定。改 m 或 k 會移動共振頻率；如果機器轉速固定，移開共振點也是一種解法，但在新的共振點，振幅仍然由阻尼器決定。
4.7

共振需要時間累積

出處：Ch4 講義 2.4–2.7

開場問題

一場地震的強震段只有幾秒，結構來得及「共振」到 \(1/2\xi\) 那麼大嗎？

從靜止開始、在 \(\beta = 1\) 受力，由 \(u(0) = \dot u(0) = 0\) 決定暫態常數後，反應比 \(R(t) = u/\rho_s\) 在小阻尼下可近似為：

\[ R(t) \approx \frac{1}{2\xi}\left(e^{-\xi\omega t} - 1\right)\cos\omega t \qquad\Rightarrow\qquad \text{振幅} = \frac{1}{2\xi}\left(1 - e^{-\xi\omega t}\right) \]

振幅從零開始，以指數方式趨近 \(1/2\xi\)。到達 63 %（\(1 - 1/e\)）時 \(\xi\omega t = 1\)，換算成圈數：

\[ n_{63\%} = \frac{\omega t}{2\pi} = \frac{1}{2\pi\xi} \]
推導：完整解與無阻尼極限
  1. \(\beta=1\) 時 \(\varphi = 90°\)，穩態為 \(u_p = -(\rho_s/2\xi)\cos\omega t\)。
  2. \(u(0) = 0\)：\(B = \rho_s/2\xi\)。\(\dot u(0)=0\)：\(-\xi\omega B + A\omega_D = 0\)，所以 \(A = \xi\omega B/\omega_D\)。
  3. \(R(t) = \dfrac{1}{2\xi}\left[e^{-\xi\omega t}\left(\cos\omega_D t + \dfrac{\xi}{\sqrt{1-\xi^2}}\sin\omega_D t\right) - \cos\omega t\right]\)；小阻尼時 \(\omega_D \approx \omega\)、sin 項很小，得到上面的近似式。
  4. \(\xi \to 0\) 時第一項是 0/0，用 L'Hôpital 對 \(\xi\) 微分：\(R(t) = \tfrac12(\sin\omega t - \omega t\cos\omega t)\)。包絡線 \(\omega t/2\) 線性成長，每圈增加 \(\pi\) 倍靜態變位。
阻尼的兩個相反效果

阻尼小 → 最終振幅大，但要累積很久；阻尼大 → 振幅小，但很快到達。\(\xi = 0.05\) 約 3.2 圈到 63 %，\(\xi = 0.15\) 約 1 圈。只有幾個強震圈的短促地震，可能推不到輕阻尼結構的共振振幅：延時和頻率內容一樣重要。沒有阻尼時振幅會無限制地成長，真實系統則有阻尼，大振幅時材料也會變成非線性，所以反應有限。

小測驗
ξ = 0.05 的系統由靜止開始在共振頻率受力，大約幾圈後振幅達到穩態值的 63 %？
n = 1/(2πξ) = 1/(2π × 0.05) = 3.18 圈。這也是暫態衰減到 1/e 所需的圈數。
4.8

每圈消散的能量與阻尼比的能量定義

出處：Ch4 講義 2.8–2.9

阻尼力一圈所做的功，就是每圈消散的能量。代入 \(\dot u = \bar\omega\rho_d\cos(\bar\omega t-\varphi)\)，\(\cos^2\) 一週期平均為 ½：

\[ W_D = \oint c\dot u\,du = \int_0^{2\pi/\bar\omega} c\dot u^2\,dt = \pi c\bar\omega\rho_d^2 \]

三件事：與振幅平方成正比（振幅加倍、能量四倍）、與頻率成正比、與 \(c\) 成正比。阻尼力對位移作圖是一個橢圓，橢圓面積就是 \(W_D\)；總力（彈簧＋阻尼）對位移則是傾斜的橢圓，面積相同。

最大彈性能 \(W_S = \tfrac12 k\rho_d^2\)。兩者相除，\(\rho_d\) 消去：

\[ \frac{W_D}{4\pi W_S} = \frac{\pi c\bar\omega\rho_d^2}{2\pi k\rho_d^2} = \xi\beta \qquad\xrightarrow{\;\beta=1\;}\qquad \xi = \frac{W_D}{4\pi W_S} \]
為什麼土壤的阻尼比不帶 β

黏滯阻尼器每圈消散的能量隨頻率增加。但在地震頻率範圍內，土壤每圈消散的能量幾乎與頻率無關：它來自顆粒接觸面的摩擦滑動（遲滯阻尼），迴圈面積只由應變振幅決定。所以土壤（8.4）直接用一個迴圈定義 \(\xi = W_D/(4\pi W_S)\)，也就是「讓等值的黏滯阻尼器在共振時每圈消散相同能量」。不需要真的有阻尼器，任何迴圈形狀都適用。

與頻率無關的阻尼：複數勁度

若要每圈損失固定，阻尼係數必須隨頻率變小：\(c = 2\xi k/\bar\omega\)。代入彈簧＋阻尼的力 \((k + ic\bar\omega)u\)，頻率消去：

\[ k^* = k(1 + 2i\xi) \qquad\Longleftrightarrow\qquad G^* = G(1 + 2i\xi) \]

虛部就是能量損失，應力領先應變一個小角度（\(\tan = 2\xi\)）。它只適用於穩態簡諧運動，不是時間域的定律。等值線性地盤反應程式（單元 10、11）和共振柱的阻尼模擬（單元 9）用的都是它。

例：反覆三軸試驗的迴圈

迴圈面積 0.20 kJ/m³，原點到迴圈尖端的三角形面積 0.16 kJ/m³ → \(\xi = 0.20/(4\pi \times 0.16) = 0.0995 \approx 10\%\)。迴圈面積是 \(W_D\)、三角形是 \(W_S\)（單元 8 寫作 \(E_D\)、\(E_{So}\)）。

把隔振墊的實測參數代入，在 \(\beta = 1\) 與 0.5 算出焦耳，驗證比值等於 \(\xi\beta\)：見 HW3 Q4(c)。

小測驗
黏滯阻尼器在 β = 0.5 時，WD/(4πWS) 等於多少？
W_D/(4πW_S) = ξβ = 0.5ξ。黏滯阻尼的比值隨頻率改變，只有在共振時才等於 ξ；這也是土壤試驗要用能量直接定義阻尼比的原因。
4.9

量阻尼比的三種方法

出處：Ch4 講義 2.10–2.13

方法 a：自由振動衰減（對數遞減）

次阻尼自由振動中，相隔一個阻尼週期的兩個峰，cos 回到同一值，比值只剩指數比，而且與挑哪兩個峰無關，這是線性系統的特徵：

\[ \delta = \ln\frac{u_n}{u_{n+1}} = \frac{2\pi\xi}{\sqrt{1-\xi^2}} \approx 2\pi\xi, \qquad \delta = \frac{1}{m}\ln\frac{u_n}{u_{n+m}}, \qquad \xi = \frac{\delta}{\sqrt{4\pi^2+\delta^2}} \approx \frac{\delta}{2\pi} \]

相鄰兩峰幾乎一樣高，差值會被讀數誤差淹沒，所以要隔 \(m\) 圈量。共振柱就是用這個方法：在共振頻率驅動試體，關掉驅動，記錄頂蓋的自由衰減，把 ln(峰值) 對圈數畫直線，斜率就是 \(-\delta\)。點不在直線上，表示阻尼與振幅有關，試體已進入非線性。

例

第 1 峰 10 mm、第 6 峰 4 mm：\(m = 5\)，\(\delta = \ln 2.5 / 5 = 0.183\)，\(\xi = 0.183/2\pi = 2.9\%\)。

方法 b：共振放大

共振振幅除以靜態變位 \(= D_{max} \approx 1/2\xi\)，所以 \(\xi \approx \rho_s/(2\rho_{max})\)。兩個弱點：靜態變位常常小到量不到；阻尼小時峰很尖，掃頻太粗會錯過峰頂。例：\(\xi = 0.02\)，掃頻只偏離共振 1 %（\(\beta = 0.99\)），\(D\) 從 25 掉到 22.5，反算的阻尼比就高估約 11 %。

方法 c：半功率頻寬

在共振曲線上找振幅降到峰值 \(1/\sqrt2\) 的兩個頻率 \(f_1\)、\(f_2\)。振動能量正比於振幅平方，\((1/\sqrt2)^2 = 1/2\)，所以叫「半功率」：

\[ \xi \approx \frac{f_2 - f_1}{2f_n} \approx \frac{f_2 - f_1}{f_2 + f_1} \]
推導：半功率點
  1. 令 \(D = \frac{1}{\sqrt2}\cdot\frac{1}{2\xi}\)，取倒數再平方：\((1-\beta^2)^2 + 4\xi^2\beta^2 = 8\xi^2\)。
  2. 令 \(x = \beta^2\)：\(x^2 - (2-4\xi^2)x + (1-8\xi^2) = 0\)，判別式 \(16\xi^2(1+\xi^2)\)。
  3. \(\beta^2 = 1 - 2\xi^2 \pm 2\xi\sqrt{1+\xi^2} \approx 1 \pm 2\xi\)，再用 \(\sqrt{1+\varepsilon} \approx 1 + \varepsilon/2\)：\(\beta_{1,2} \approx 1 \mp \xi\)。
  4. \(\beta_2 - \beta_1 \approx 2\xi\)，換回頻率即得上式；\(\xi < 10\%\) 時誤差只有幾 %。

它不需要靜態變位，也不需要振幅的絕對尺度，只要曲線的形狀；但仍要讀準峰值，因為峰值決定 \(1/\sqrt2\) 的高度。例：共振 50 Hz、半功率點 48.5 與 51.5 Hz → \(\xi = 3/100 = 3\%\)。

4.10

傳遞率：隔振與隔震

出處：Ch4 講義 2.14–2.15

情況 a：機器的力傳到地面多少？

機器產生 \(p_0\sin\bar\omega t\)，經彈簧與阻尼器傳到地面。彈簧力幅值 \(p_0D\)、阻尼力幅值 \(2\xi\beta p_0D\)，兩者差 90°，平方和開根號：

\[ TR = \frac{F_{\text{傳到地面}}}{p_0} = D\sqrt{1 + (2\xi\beta)^2} \]

情況 b：地面在搖，質量動多少？

地面 \(u_g = u_{g0}\sin\bar\omega t\)。慣性力作用在總加速度上，彈簧與阻尼器只感受相對運動，等效外力為 \(-m\ddot u_g\)。結果：

\[ \frac{u^t_{max}}{u_{g0}} = D\sqrt{1 + (2\xi\beta)^2} \;(=TR), \qquad \frac{u_{max}}{u_{g0}} = \beta^2 D \;\;(\text{相對位移，即彈簧伸長量}) \]

力由質量傳到地面、運動由地面傳到質量，是同一個函數。兩者都等於 \(|k + ic\bar\omega| / |k - m\bar\omega^2 + ic\bar\omega|\)：分子是傳遞的彈簧與阻尼器，分母是系統的動態勁度。

推導：TR 的兩個關鍵
  1. 所有曲線在 \(\beta = \sqrt2\) 通過 \(TR = 1\)：\(\beta^2 = 2\) 時 \((1-\beta^2)^2 = 1\)，\(TR^2 = (1+8\xi^2)/(1+8\xi^2) = 1\)，與 \(\xi\) 無關。
  2. \(\beta > \sqrt2\) 時 \((1-\beta^2)^2 > 1\)，\(TR^2 = (1+4\xi^2\beta^2)/((1-\beta^2)^2+4\xi^2\beta^2) < 1\)；分子分母加同一個正數 \(4\xi^2\beta^2\) 會把比值往 1 推，所以阻尼越大，傳遞越多。
  3. 地動情況：相對位移 \(u = \beta^2u_{g0}D\sin(\bar\omega t-\varphi)\)，總位移 \(u_g + u\) 用餘弦定理相加，並用 \(\cos\varphi = D(1-\beta^2)\)，整理後與 \(D^2(1+4\xi^2\beta^2)\) 相同。

兩個設計結論

  1. 要隔振，\(\beta\) 必須大於 \(\sqrt2\)：支承的自然頻率要低於運轉頻率 / 1.41。支承要做軟，和「基礎做剛一點比較好」的直覺相反。
  2. 在隔振區，阻尼越大傳遞率越高：阻尼器是力進入地面的第二條路徑。但機器啟動、停止時會通過 \(\beta = 1\)，還是需要阻尼。很少啟動的機器用輕阻尼，整天開開關關的機器用較大阻尼。
例：1800 rpm 的機器

1800 rpm = 30 Hz。要 \(TR < 1\)：\(f_n < 30/1.41 = 21\) Hz。要 \(TR < 10\%\)（阻尼可忽略）：\(TR \approx 1/(\beta^2-1)\) → \(\beta = \sqrt{11} = 3.3\) → \(f_n \approx 9\) Hz，機器自重下的靜態沉陷 \(g/\omega^2 \approx 3\) mm。

例：基礎隔震

固定基底週期 0.5 s 的建築加上隔震器，週期拉長到 3 s；地震主要週期約 0.5 s → \(\beta = 3/0.5 = 6\)。輕阻尼時 \(TR \approx 1/35 \approx 3\%\)；隔震器刻意給 15 % 阻尼以限制位移，\(TR\) 約 6 %，仍大幅降低。代價是相對位移：\(\beta\) 大時 \(\beta^2D \to 1\)，隔震層要伸長整個地表位移，所以隔震建築周圍要留隔震溝。

常見陷阱

  • D 的兩種意思：本單元的 D 是放大因子，單元 8、9 的 D 是阻尼比。
  • ω 與 f 差 2π：ω 單位 rad/s，f 單位 Hz；T = 2π/ω。
  • β > 1 的相位：tan⁻¹ 會給負角，要加 180° 或用 atan2。
  • 共振峰的位置：嚴格來說在 √(1−2ξ²)，不在 β = 1；小阻尼時差異可忽略。
  • 對數遞減的分母：δ = 2πξ/√(1−ξ²)，「δ = 2πξ」是小阻尼近似，要寫「≈」。
  • 掃頻太粗：錯過峰頂 → 共振放大法高估阻尼；半功率法也需要準確的峰值。
  • 大應變不是線性系統：共振曲線傾斜時半功率法高估阻尼，改用自由衰減。
  • 隔振要軟不要硬：β > √2 才有隔振效果；隔振區的阻尼反而增加傳遞。
