等值線性與非線性分析

讓土壤性質跟著應變走。等值線性分析反覆更新每一層的 \(G\) 與 \(\xi\)，直到與算出的應變相容；應變太大時改用時間域的非線性分析；地形與結構物不再是水平成層時，就需要二維與三維模型。

11.1

等值線性分析：用疊代逼近非線性

出處：Ch6 講義 2.16–2.22；教師 PDF p.34–40；郭安妮講義 p.9–10

開場問題

\(G\) 和 \(\xi\) 隨應變改變，頻率域分析卻必須是線性的。每一層只能有一組 \(G\)、\(\xi\)，該選哪一組？

等值線性法的回答：用一組與應變相容的性質，代表整個地震期間的平均行為。要讀曲線就要選一個應變。\(\gamma_{max}\) 只出現一瞬間，大部分時間應變較小，用它讀曲線會高估非線性；所以用有效應變：

\[ \gamma_{eff} = R_\gamma\,\gamma_{max}, \qquad R_\gamma = \frac{M-1}{10}\quad(\text{Idriss \& Sun, SHAKE91}) \]

規模越大、強震延時越長、接近最大應變的圈數越多，有效應變就該越接近最大應變。文獻值 0.5–0.7 都有，是本方法較主觀的參數之一；Strata 讓使用者設定，常用預設 0.65。同樣的 0.65 會在 Ch8 再出現：簡化液化評估法的平均反覆剪應力也取最大值的 0.65 倍，想法相同。

五個步驟

  1. 每一層以小應變的 \(G_{max}\)、\(\xi_{min}\) 為初值。
  2. 做一次線性地盤反應分析，得到每一層的剪應變歷時（6.8 的應變轉換函數 → 逆 FFT）。
  3. 由每一層的 \(\gamma_{max}\) 求 \(\gamma_{eff} = R_\gamma\gamma_{max}\)。
  4. 由 \(\gamma_{eff}\) 從曲線讀出新的 \(G\)、\(\xi\)，再做一次分析。
  5. 重複 2–4，直到每一層都滿足 \(|G_j^{(i+1)} - G_j^{(i)}|/G_j^{(i+1)} \le 5\,\%\)，\(\xi\) 亦同（講義寫的 \(\xi_J\) 下標應為 \(\xi_j\)，勘誤表第 38 頁）。

通常 5–8 次即可收斂。應變增加時 \(G\) 下降、\(\xi\) 上升，兩者都降低高頻放大，所以軟弱場址在強震下的放大常比弱震小。收斂後以固定性質再做一次線性分析，得到地表運動、反應譜、每一層的最大應力與應變。計算反應時 \(G\)、\(\xi\) 在整段歷時中固定：最強的幾秒和微弱的尾段用同一組性質，所以它仍是線性分析，這也是它最大的限制（11.3）。

例：多層剖面的等值線性結果（講義 2.21–2.22 與本頁重算）

剖面同 6.8；曲線用講義表（應變 \(10^{-4}\) % 到 10 %，\(G/G_{max}\) 1.00 → 0.04，\(\xi\) 3 % → 30 %；最小阻尼 3 %，即單元 8 的 \(D_{min}\)）。講義用 Kramer 書中的輸入（岩盤 PGA 近 0.5 g），得到：第一峰由 0.9 Hz 移到 0.5 Hz 以下，5 Hz 以上幾乎完全被抑制，地表 PGA 約 0.3 g，比輸入小（去放大）。

本頁拿不到那筆輸入，改用 CHY086 紀錄調到 0.5 g、\(R_\gamma\) = 0.65 重算：6 次疊代收斂；最軟的幾個子層 \(G/G_{max}\) 降到約 0.2、最大應變約 0.8 %；第一峰由 0.90 Hz 移到約 0.65 Hz，高頻放大大幅下降。趨勢與講義相同，但這筆輸入的地表 PGA 仍大於輸入（放大倍率由 0.1 g 時的 2.3 降到 0.5 g 時的 1.6）：會不會去放大，取決於輸入的頻率內容，不是剖面本身決定的。

反摺積（deconvolution）

分析是線性的，所以可以倒著做：把地表紀錄除以轉換函數，反推岩盤或任一層的運動，再施加到附近場址。只在轉換函數不接近零的頻率可行，否則雜訊被大幅放大。真正的非線性分析無法這樣由地表往回推。

小測驗
等值線性分析的報告附上「最大剪應變 vs 深度」。圖上畫的應該是哪一個？

常見陷阱：整個土柱用同一條曲線

圍壓隨深度增加，同一種土在深處的曲線應較線性（往右移）。整個土柱用同一條曲線會高估深層的非線性。曲線可以來自室內試驗，或 Darendeli 等依 PI 與圍壓的模型（8.9）。疊代 10 次以上仍不收斂，多半是某一層應變很大：檢查該層的輸入參數，或改用非線性分析，而不是一直增加疊代次數。

11.2

實務議題：子層厚度與隱含剪力強度

出處：Ch6 講義 3.2–3.3；教師 PDF p.42–43

開場問題

均勻層明明有封閉解，為什麼程式還要把它切成一公尺左右的子層？曲線讀出來的 G，又為什麼可能違反物理？

子層厚度

若只解波動方程式，均勻層不必切。但等值線性法中每個子層只有一個有效應變、一組 \(G\)、\(\xi\)，而實際應變與圍壓隨深度變化，子層要薄到能跟上這個變化，也要能表示要分析的最短波長：

\[ \lambda_{min} = \frac{V_s}{f_{max}}, \qquad h \le \frac{\lambda_{min}}{5} \sim \frac{\lambda_{min}}{8} \]

\(f_{max}\) 一般結構取 20–25 Hz，剛性設備更高。軟土速度低、波長短，子層最薄；深處硬層可較厚。輸入紀錄也要支援同一個 \(f_{max}\)：\(\Delta t\) = 0.02 s 的紀錄 Nyquist 只有 25 Hz。基盤深達數百公尺時，基盤深度與深層 \(V_s\) 的不確定性，常比子層厚度更影響結果。

隱含剪力強度

G/Gmax 曲線加上 \(V_s\)（也就是 \(G_{max}\)），其實就隱含了完整的應力應變曲線：

\[ \tau(\gamma) = \frac{G}{G_{max}}(\gamma)\cdot G_{max}\cdot\gamma \]

在大應變時，這條隱含曲線可能一路上升到超過土壤的剪力強度（黏土用 \(S_u\)、砂用 \(\sigma'_v\tan\phi'\)），等於聲稱土壤承受比強度更大的剪應力，物理上不可能。\(\gamma_{max}\) > 0.1 % 的每一層都要檢查，軟黏土最常出問題。

例：正常壓密黏土，深 10 m

\(\sigma'_v \approx 100\) kPa，\(S_u \approx (0.2\text{–}0.3)\sigma'_v\) ≈ 20–30 kPa。\(G_{max}\) = 20 MPa，通用曲線在 1 % 給 \(G/G_{max}\) = 0.15：隱含應力 = 0.15 × 20,000 kPa × 0.01 = 30 kPa。若 \(S_u\) = 25 kPa，曲線已超過強度，必須修正。修正方法是強度修正曲線（strength-adjusted curves）：修改大應變段，讓曲線趨近強度時變平；DEEPSOIL 等程式提供此選項。上方互動圖按「NC 黏土例」重現（雙曲線 \(\gamma_r\) = 0.176 % 在 1 % 剛好給 0.15）。

小測驗
\(G_{max}\) = 20 MPa，曲線在 \(\gamma\) = 1 % 時 \(G/G_{max}\) = 0.15。隱含的剪應力是多少 kPa？
τ = 0.15 × 20,000 kPa × 0.01 = 30 kPa。若該層的 S_u 只有 25 kPa，不修正曲線會讓這個弱層往上傳遞過多剪應力，高估地表加速度。
常見陷阱：只看 G/Gmax 曲線形狀

兩條形狀相同的 G/Gmax 曲線，配上不同的 \(G_{max}\)，隱含強度可以差好幾倍。養成習慣：畫出每一層的隱含應力應變曲線，和強度放在同一張圖比較。

11.3

等值線性的限制與時間域非線性分析

出處：Ch6 講義 3.4–3.10；教師 PDF p.44–58

開場問題

如果土壤的勁度在強震段變軟、在尾段又變硬，一組固定的 \(G\)、\(\xi\) 會錯在哪裡？

等值線性的六個限制

  1. 高頻被過度阻尼：\(\gamma_{eff}\) 主要由大而低頻的運動控制；高頻分量的應變小、應該只有小阻尼，卻用同一個大阻尼，地表高頻反應被低估。與紀錄比較，極軟場址受強震時約 5 Hz 以上的譜值常被低估，1 s 附近通常尚可。
  2. \(\gamma_{max}\) 超過約 0.5–1 % 不可靠：極軟層變得極軟、高阻尼，像上下土層之間的隔震墊，地表加速度可能被嚴重低估。近破壞的軟層幾乎不傳剪力，真正的問題變成大變形，而等值線性法算不出來。
  3. 總應力分析：不能產生超額孔隙水壓、不能算永久變形，無法模擬液化過程。
  4. 一維：忽略表面波、地形與盆地邊緣效應。
  5. 不確定性：\(V_s\) 剖面與曲線都不確定，一次分析只給一個答案；用 Monte Carlo 產生大量剖面與曲線（Strata 有此功能），至少做上、下限分析。
  6. 它仍是最廣泛使用、校核最充分的方法，中等應變下相當可靠。正確的態度是知道它的適用範圍。

每次等值線性分析後看三張圖：最大剪應變 vs 深度（有沒有層超過 0.5–1 %）、收斂後的 \(G/G_{max}\) 與阻尼 vs 深度（是否合理）、地表頻譜 / 輸入頻譜。

時間域逐步積分：顯式差分

真正的非線性分析在時間域逐步積分，每一步依當下的應力與應變更新模數。土柱切成 N 個子層，每個節點有位移與速度。一片厚 \(\Delta z\) 的土，速度變化由上下兩面的剪應力差決定（單位面積的牛頓第二定律，質量 \(\rho\Delta z\)）：

\[ \frac{\partial\tau}{\partial z} = \rho\frac{\partial\dot u}{\partial t} \quad\Rightarrow\quad \dot u_i^{\,t+\Delta t} = \dot u_i^{\,t} + \frac{\Delta t}{\rho\,\Delta z}\left(\tau_{i}^{\,t} - \tau_{i-1}^{\,t}\right), \qquad \tau_0 = 0\ (\text{地表}) \]

由目前的速度與應力直接得到下一步的速度，不解聯立方程，這就是顯式。代價是時間步長要小：一步之內波不能穿過一個以上的子層，\(\Delta t < \Delta z/V_s\)。例：臨界子層 1 m、\(V_s\) = 200 m/s → \(\Delta t\) < 0.005 s，實務上常把輸入紀錄的一個時間步再分成數個計算步。對照反應譜（5.2）用的 Newmark 法（可為隱式、每步解方程），這裡較簡單，但步長受穩定性限制。

底部邊界：把 outcrop、阻抗比收進一個阻尼器

  • 剛性基盤：底部節點的速度 = 輸入基盤速度。能量出不去，振盪持續很久。
  • 彈性基盤（傳遞邊界、Lysmer 邊界）：在底部放一個係數等於岩盤阻抗 \(\rho_rV_r\) 的阻尼器，邊界剪應力 \(\tau_b = \rho_rV_r(2\dot u_I - \dot u_b)\)。入射速度 \(\dot u_I\) = 露頭紀錄 / 2（6.2 的因子 2）。它吸收下行波，讓能量離開土層：6.2 的 outcrop / within、6.7 的阻抗比與輻射阻尼，在時間域都化成這一個阻尼器。
  • 若輸入是 within 紀錄，應像剛性基盤一樣直接指定底部節點的運動，不乘 2，否則反射被算兩次。

每個子層的應力應變

位移增量 \(\Delta u = \dot u\Delta t\) → 子層剪應變 \(\gamma = (u_{i+1} - u_i)/\Delta z\) → 剪應力。非線性時用單元 8 的骨架曲線＋Masing 規則：依載重歷史判斷初次載重、卸載或再載入，每個子層一步一步沿著遲滯迴圈走。早期程式（CHARSOIL、DESRA-2、DYNA1D、MASH、NONL13、TESS1）的差別只在骨架的數學形式與阻尼、強度的處理；今日的 DEEPSOIL 非線性模式、OpenSees 架構相同。非線性模型在小應變幾乎線性、迴圈很細，所以通常另加少量黏滯阻尼代表 \(D_{min}\)，這個黏滯阻尼怎麼加是重要的不確定來源。

與等值線性最根本的差別

等值線性：整段紀錄一個割線模數，對整段紀錄重複疊代。非線性：每一個時間步跑一次積分流程（① 已知各界面 \(u, \dot u\) → ② 各層應變 → ③ 應力應變律求應力 → ④ 由輸入定出基盤運動 → ⑤ 由下往上更新各界面），沒有疊代；強震段軟、微弱尾段再變硬，高頻過度阻尼的問題自然消失。40 s 紀錄、\(\Delta t\) = 0.005 s 是 8000 步，在 1970 年代這是等值線性法較流行的重要原因。

怎麼選？

老師最希望記住的一句：非線性分析不會自動比較好，它只和它的率定與黏滯阻尼模型一樣好。一般場址先做等值線性；最大應變超過約 0.5 %、可能液化、或需要永久變形時，再加做非線性分析，並以等值線性結果當基準：中等應變時兩者應接近，差很多時通常是某個輸入錯了。等值線性在一般電腦上只要數秒，數百組隨機剖面很容易；有效應力非線性要數分鐘到數十分鐘，參數率定可能要數天。有些程式提供頻率相依的等值線性法，可部分改善過度阻尼。

11.4

二維與三維動力分析

出處：Ch6 講義 4.1–4.10；教師 PDF p.59–70

開場問題

土壩、擋土牆、隧道：哪些情況「水平成層」的假設不成立？二維模型又要避開哪些陷阱？

共同特徵是：一個方向很長、斷面不是水平成層、或土中有結構物。長土壩真實是三維，但壩夠長時取中央斷面，以平面應變模擬即可。主要工具是動力有限元素法，和一維一樣有等值線性與非線性兩種做法。

全域運動方程式與 Rayleigh 阻尼

\[ [M]\{\ddot u\} + [C]\{\dot u\} + [K]\{u\} = -[M]\{1\}\,\ddot u_b(t), \qquad [C] = a_0[M] + a_1[K] \]

就是單元 4 基底激振 SDOF 推廣到多自由度。阻尼矩陣常用 Rayleigh 阻尼：兩個係數由兩個頻率的目標阻尼比決定，兩頻率之間阻尼偏低、之外偏高，所以頻率的選擇會影響結果（下方互動圖第二頁）。

離散化與邊界

  • 空間：元素尺寸 < (1/5–1/8) 最短波長，與一維子層同一規則；節點太疏會濾掉高頻，這是數值濾波，不是物理濾波。
  • 時間：\(\Delta t\) < 要模擬的最短週期 / 10；顯式法還要滿足穩定條件，二維用壓縮波速，比 \(\Delta z/V_s\) 更嚴。例：土壩 \(V_s\) = 250 m/s 模擬到 10 Hz → \(\lambda_{min}\) = 25 m，元素約 3–5 m；最短週期 0.1 s → \(\Delta t\) ≤ 0.01 s。先粗網格再加密，確認結果收斂。
邊界做法優點限制
基本邊界固定位移簡單箱效應：反射能量困在模型內，模型要非常大
局部邊界阻尼器（一維用過的 Lysmer 邊界）吸收大部分能量斜入射吸收不完全，效果與入射角、與結構距離有關
一致邊界集中質量＋彈簧＋阻尼器所有角度、頻率複雜、頻率相依，多用於頻率域程式

簡單檢查：模型寬度加倍再跑一次，結果變很多，表示邊界仍在影響。

二維等值線性與非線性

二維等值線性和 SHAKE 同一個想法，轉換函數變成矩陣 \(\{U(\omega)\} = [K^* - \omega^2M]^{-1}\{\cdots\}\)，\(K^*\) 是含阻尼的複數勁度矩陣（FLUSH、Ground2D）。每個頻率要解數千到數萬個自由度，只算有限個頻率、其餘內插。疊代以元素為單位，不是以層為單位：土壩同一高程，壩頂和壩趾的應變可能差很多。二維非線性（FLAC2D、TARA-3、DYNAFLOW、DYANA）在時間域逐步積分；擴展 Masing 規則加孔隙水壓模型可做有效應力分析、模擬液化（Ch8）。最大障礙是參數難以取得；PM4Sand 等新模型用少量有物理意義、可由 SPT、CPT 率定的參數。

剪力梁法與鞭梢效應

把土壩切成許多水平薄片，假設每片只做水平剪切（同高程各點水平位移相同），上下表面的剪力差等於薄片的慣性力：二維土壩變成寬度隨高度變化的一維剪力梁。均勻勁度的三角形壩，Gazetas (1982) 給出以 Bessel 函數表示的封閉解：

\[ \phi_n(z) = J_0\!\left(\beta_n\frac{z}{H}\right),\quad J_0(\beta_n) = 0,\quad \beta_n = 2.405,\ 5.520,\ 8.654;\qquad T_n = \frac{2\pi H}{\beta_n V_s},\quad T_1 = 2.61\frac{H}{V_s} \]

\(z\) 由壩頂往下量。壩頂附近斷面變窄、質量變小，第二、第三振態在壩頂附近的位移變化非常劇烈，運動被強烈放大，像鞭梢比手快得多，這就是鞭梢效應（whiplash）。土壩震害常見壩頂附近的縱向裂縫或局部滑動，耐震設計中壩頂加速度取得比基底大很多。

例：壩高 50 m、平均 Vs = 300 m/s

\(T_1 = 2\pi \times 50/(2.405 \times 300) = 0.435\) s，落在講義說的 0.4–0.5 s。同樣 50 m 厚的均勻土層 \(4H/V_s\) = 0.67 s：三角形斷面上窄下寬，有效勁度較高，週期較短。審查報告時可用來檢核有限元素分析。

三維

三種情況需要三維：土壤條件在三個方向都變化很大；窄峽谷中的土壩（峽谷壁束制兩端，平面應變不成立）；強烈的土壤–結構互制（相鄰高樓、鄰近地下結構）。方法和二維類似（等值線性如 SASSI，非線性如 FLAC3D、ABAQUS），計算與參數都昂貴，主要用於重要結構，例如大型捷運車站與隧道、高樓與鄰近深開挖的互制。你要能判斷為何需要三維、結果是否合理。

小測驗
二維等值線性分析一座土壩，為什麼疊代必須逐元素、不能每一高程取一個平均應變？
一維的「每層一組 G、ξ」靠的是水平成層：同一深度應變相同。土壩斷面不是水平成層，同一高程的應變分布不均，所以應變相容要以元素為單位。

重點整理

常見陷阱

  • 收斂準則的下標：講義的 ξJ 應為 ξj（第 j 層）。
  • 報告的應變：最大應變剖面是 γmax，不乘 Rγ。
  • 同一條曲線用到底：深層圍壓大、曲線應較線性；也要檢查隱含強度。
  • γ > 0.5–1 % 還信等值線性：軟層像隔震墊，地表加速度被低估、大變形算不出來。
  • 逐字稿用詞：Cramer → Kramer、Lismar → Lysmer、Idris and Son → Idriss & Sun、macing / Mason / amazing rule → Masing rule、Dharandelis → Darendeli、Ramburg-Oskud → Ramberg–Osgood、Gazettas → Gazetas、open seas → OpenSees、flax → FLAC、Terra 3 → TARA-3、DYA → DYANA、Nequis → Nyquist。
  • 等值線性不算孔隙水壓：γ > γtv 時要配合 Ch8 液化評估或有效應力分析。

自我檢測

綜合題 1
等值線性分析得到某層 γmax = 1.5 %，地表 PGA 比岩盤 PGA 小很多。最恰當的下一步是？
γ > 0.5–1 % 已超出等值線性的可靠範圍：極軟層像隔震墊，地表加速度被低估，真正的問題是大變形。先檢查曲線是否超過強度，再用非線性分析（以等值線性為基準）比較。增加疊代次數不能解決模型本身的限制。
