哪一個太硬：Global maximum 在 1.3–2.3 m 造出一層假的 498 m/s，2–8 m 平均 190 m/s，比真值 140 m/s 硬 36 %。

為什麼失敗：反算只計算基本模態、把每個點都當基本模態；高階模態永遠比較快（這裡快 16–56 %），22.7–49.1 Hz 的快速高頻點就被解釋成一層淺而硬的假層。模態跳躍是階梯，任何基本模態曲線都跟不上，所以 RMS 停在 7.2 %。

為什麼門檻用 0.15：預設 0.6 時 22 Hz 以上的基本模態峰低於最大值的 0.6 而被略過，結果和 Global maximum 完全相同；0.2 時仍有 18 點在高階模態，0.1 時幾乎全落在雜訊上。但門檻低時，由低速往上找的第一個峰常是基本模態下方的雜訊，許多點掉到 70–130 m/s，反算變得太軟（114 m/s），又因為這些點不在任何模態上，RMS 高達 43 %。報告另做了沿基本模態的手動拾取（RMS 4.15 %，只剩 2 點在高階模態），是三者中最可信的。

飽和時 Vp：\(V_p = V_s\sqrt{(2-2\nu)/(1-2\nu)}\)，180 m/s 的層在 \(\nu = 0.25\) 時 \(V_p\) = 312 m/s，\(\nu = 0.49\) 時 1285 m/s，接近水的壓縮波速。孔隙水承擔體積應力，\(V_p\) 量到的是水；水沒有剪力勁度，\(V_s\) 不受影響。

頻散中幾乎看不出來：兩個 \(\nu\) 的反算都把拾取點擬合得一樣好（RMS 0.48 %、0.51 %），10、30 Hz 的相速度相同；\(V_p\) 增加約四倍，只需上兩層 \(V_s\) 改變 4–8 % 就吸收掉。Rayleigh 波由剪力主導（均質半無限域 \(c_R/V_s\) 只從 0.92 變到 0.95），資料分辨不出 \(\nu\)。用正確的 0.49 時，17 m 走時平均 \(V_s\)（220 m/s）較接近真值 210 m/s（0.25 時 254 m/s）。

量到的模數：MASW 量 \(V_s\)，也就是小應變剪力模數 \(G_{max} = \rho V_s^2\)（180 m/s 層約 61 MPa）。錘擊的應變小於 \(10^{-4}\,\%\)，屬線彈性，是 \(G/G_{max}\) 曲線的起點，不是地震應變下的模數。

7.2 的互動圖用自己的分層 Rayleigh 波求解器計算同樣三個場址的理論模態；用 Q1(c) 反算得到的模型（140 / 181 / 402 m/s，\(\nu\) = 0.49）驗算，10 Hz 得 196 m/s、30 Hz 得 144 m/s，與實驗室圖上讀到的 197、145 m/s 一致。

\(V_{s30} = 30/0.1192 = \mathbf{251.7}\) m/s；算術平均 \(= 9100/30 = 303.3\) m/s（高 20 %）。算術平均以厚度加權、走時平均以波停留的時間加權：軟黏土只占 17 % 厚度，卻占 35 % 走時。規範用走時平均，因為場址反應由走時（場址週期 \(T \approx 4H/V_{s30} = 0.48\) s）與阻抗對比控制，兩者都由軟層主導。

Q2(b) 三套分類系統

臺灣規範（111 年版，2.5 節）：第一類（堅實）\(V_{s30} \ge 270\)；第二類（普通）\(180 \le V_{s30} < 270\)；第三類（軟弱）\(V_{s30} < 180\)；臺北盆地另依臺北一、二、三區微分區，不以 \(V_{s30}\) 分類。

Q2(a) 場址（251.7 m/s）：NEHRP D、Eurocode 8 C、臺灣第二類。（若誤用算術平均 303 m/s，臺灣會變成第一類。）

界線差異：NEHRP 與 EC8 共用 180、360，但岩盤界線 760 對 800，且只有 NEHRP 分出 A 硬岩（≥ 1500）。臺灣只有三類，下界同為 180，上界 270 落在 NEHRP D／EC8 C 中間，比 270 硬的從密實土到岩盤都是同一類。最細的是 NEHRP（五個 \(V_{s30}\) 類別加 F）。

沒有實測 Vs 時：用式 2-5b（黏性土）、2-5c（砂質土）由 N 值或 \(q_u\) 估各層 \(V_s\)，再算 \(V_{s30}\)（見 7.5）。

Q2(c) 一層薄軟土

\(V_{s30} = 30/(0.1250 + 0.0333) = \mathbf{189.5}\) m/s（算術平均 426.7 m/s）→ NEHRP D、Eurocode 8 C、臺灣第二類。若用算術平均，三套都會高估一整類（C、B、第一類）。

為什麼被拉低：黏土只占三分之一厚度，但 \(V_s\) 只有風化岩的 0.13 倍，占了 79 % 走時。為什麼放大強：軟層覆於硬岩形成大的阻抗對比，密度相近時阻抗比約 80/600 ≈ 0.13，無阻尼一維土層共振時的放大約為其倒數 ≈ 7.5；共振頻率 \(f_0 = V_s/4H = 80/40 = 2\) Hz（\(T_0 = 0.5\) s），正好落在中高樓層建築的週期範圍。
