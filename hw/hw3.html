題目（原文改寫）

平坦場址由三層砂土與較硬的基盤組成，各層密度 ρ = 1.95 t/m³。從第 3 層 15 m 深處取乾淨砂（PI = 0、OCR = 1），重模到 e = 0.70、壓密到 σ′m = 100 kPa，放進固定–自由式共振柱（d = 50 mm、H = 100 mm、I/I₀ = 0.10）試驗。驅動振幅分六階段加大，每階段記錄剪應變 γ 與共振頻率 fn；接著關掉驅動，記錄自由振動連續六個峰值 X₁–X₆（Table 1）。

用到的觀念

  1. 共振柱 = 扭轉波在試體裡形成的駐波（9.1）。底部固定、頂部接一個有慣量 I₀ 的頂蓋。試體的第一個扭轉振態頻率 \(\omega_n\) 由邊界條件決定，寫成頻率方程式 \(I/I_0 = \beta\tan\beta\)，其中 \(\beta = \omega_nH/V_s\) 是「波走過試體高度所需的相位」。量到 \(\omega_n\)、解出 \(\beta\)，就能反算 \(V_s\)。
  2. 共振峰（4.5）：用固定振幅的扭矩掃頻，反應在 \(f = f_n\) 附近最大，峰的位置給 \(f_n\)，峰的寬度反映阻尼。
  3. 彈性波速與剪力模數（6.2）：\(V_s = \sqrt{G/\rho}\)，所以 \(G = \rho V_s^2\)。stage 1 應變極小（0.0005 % 低於線性門檻），量到的 G 就是 \(G_{max}\)。
  4. 對數遞減法（4.9）：關掉驅動後，次阻尼 SDOF 每一圈振幅按固定比例 \(e^{\delta}\) 縮小，\(\delta = 2\pi\xi/\sqrt{1-\xi^2} \approx 2\pi\xi\)。
頻率方程式 \(I/I_0 = \beta\tan\beta\) 從哪裡來
  1. 試體內扭轉角滿足一維波動方程式 \(\ddot\theta = V_s^2\,\theta''\)。設簡諧振動 \(\theta(z,t) = \Theta(z)\,e^{i\omega t}\)，得 \(\Theta(z) = A\sin(\omega z/V_s) + B\cos(\omega z/V_s)\)。
  2. 底部固定：\(\Theta(0) = 0 \Rightarrow B = 0\)。
  3. 頂部：試體作用在頂蓋上的扭矩 \(-GJ\,\theta'(H)\) 推動頂蓋的慣量 \(I_0\ddot\theta(H)\)：\(GJ\,\frac{\omega}{V_s}\cos\frac{\omega H}{V_s} = I_0\,\omega^2\sin\frac{\omega H}{V_s}\)。
  4. 代入 \(G = \rho V_s^2\)，兩邊乘 \(H\)，並用試體的轉動慣量 \(I = \rho JH\)：\(\dfrac{I}{I_0} = \dfrac{\omega H}{V_s}\tan\dfrac{\omega H}{V_s} = \beta\tan\beta\)。

直覺：若頂蓋遠重於試體（\(I/I_0\) 小），\(\tan\beta \approx \beta\)，得 \(\beta^2 \approx I/I_0\)，也就是 \(\omega_n^2 \approx (GJ/H)/I_0\)：試體像一根扭轉彈簧 \(k = GJ/H\)，頂蓋是質量，回到單元 4 的 SDOF。

步驟 1：從頻率響應曲線找共振頻率 \(f_n\)

加速度計量的是頂蓋的加速度，扭矩振幅固定，所以量測曲線是 SDOF 的加速度頻率響應（位移響應乘上 \(\omega^2\)）：

\[ A(f) = \frac{A_0\,r^2}{\sqrt{(1-r^2)^2 + (2\xi r)^2}}, \qquad r = \frac{f}{f_n} \]

用三種方式讀 \(f_n\)：

  • 最大量測點：108.25 Hz（60.04 mV）。點距 0.25 Hz，精度受限。
  • 三點拋物線內插：峰值與左右兩點擬合拋物線，頂點在 108.28 Hz。
  • 整條曲線最小平方擬合（採用）：對 97 點擬合上式的 \(A_0\)、\(f_n\)、\(\xi\)，得 \(f_n\) = 108.22 Hz、\(\xi\) = 1.06 %、\(A_0\) = 1.27 mV。

擬合值略低於峰值是合理的：加速度響應的峰在 \(f_n/\sqrt{1-2\xi^2}\)，比 \(f_n\) 稍高；但 \(\xi\) ≈ 1 % 時只差 0.01 %。三者和 Table 1 的 108.3 Hz 差都在 0.1 % 以內。

步驟 2：解頻率方程式求 \(\beta\)

\(\beta\tan\beta = 0.10\) 沒有解析解，用數值法求第一個根（介於 0 與 \(\pi/2\)）。以 \(\beta_0 = \sqrt{0.10} = 0.3162\) 為初值（小角度近似），牛頓法 \(\beta_{k+1} = \beta_k - \dfrac{\beta_k\tan\beta_k - 0.10}{\tan\beta_k + \beta_k\sec^2\beta_k}\)：

\[ \beta_0 = 0.3162 \;(\beta\tan\beta = 0.1035) \;\rightarrow\; \beta_1 = 0.3111 \;(0.10003) \;\rightarrow\; \beta = 0.31105\ \text{rad} \] \[ \text{驗算：}\ 0.31105 \times \tan(0.31105) = 0.31105 \times 0.32149 = 0.1000 \]

\(\beta\) 只由 I/I₀ 決定，與頻率、應變無關，所以 Q1(b) 六個階段共用同一個 \(\beta\)。

步驟 3：剪力波速 \(V_s\)

由 \(\beta = \omega_nH/V_s\) 移項：

\[ \omega_n = 2\pi f_n = 2\pi \times 108.22 = 679.94\ \text{rad/s} \] \[ V_s = \frac{\omega_nH}{\beta} = \frac{679.94 \times 0.100}{0.31105} = 218.6\ \text{m/s} \]

步驟 4：最大剪力模數 \(G_{max}\)

\[ G_{max} = \rho V_s^2 = 1.95\ \text{t/m}^3 \times (218.6\ \text{m/s})^2 = 93{,}176\ \text{kPa} \approx 93.2\ \text{MPa} \]

單位：t/m³ × m²/s² = 10³ kg/(m·s²) = kN/m² = kPa。stage 1 的 γ = 0.0005 % 低於線性門檻 \(\gamma_{tl}\)（約 0.001 %），所以這個 G 可視為 \(G_{max}\)。

步驟 5：對數遞減法求阻尼比

X₁ 到 X₆ 共六個峰、相隔 n = 5 個週期（常見錯誤是除以 6）：

\[ \frac{X_1}{X_6} = \frac{88.80}{63.39} = 1.4009, \qquad \delta = \frac15\ln 1.4009 = \frac{0.3371}{5} = 0.0674 \] \[ D \approx \frac{\delta}{2\pi} = \frac{0.0674}{6.283} = 1.07\,\% \qquad \left(\text{精確式 } \frac{\delta}{\sqrt{4\pi^2+\delta^2}} = 1.07\,\%\right) \]

驗算（同一個 stage 1，用不同資料、不同方法）：

  • 逐圈比值：\(X_i/X_{i+1}\) = 1.068、1.067、1.073、1.072、1.069，幾乎是常數，表示每圈以相同比例衰減，符合線性黏滯阻尼的假設。
  • \(\ln X\) 對週期數迴歸：斜率 \(-\delta\)，得 \(\delta\) = 0.0677、D = 1.08 %。
  • 半功率頻寬法（Figure 3）：在 \(A_{max}/\sqrt2\) = 42.45 mV 處內插得 \(f_1\) = 107.13 Hz、\(f_2\) = 109.45 Hz，\(D = (f_2-f_1)/(2f_n) = 2.31/(2 \times 108.22)\) = 1.07 %。
  • 曲線擬合的 \(\xi\) = 1.06 %。

答案：\(f_n\) = 108.22 Hz（Table 1 為 108.3 Hz）；\(\beta\) = 0.3111 rad；\(V_s\) = 218.6 m/s；\(G_{max}\) = 93.2 MPa；\(\delta\) = 0.0674，\(D\) = 1.07 %（迴歸 1.08 %、半功率 1.07 %，彼此一致）。

這個 \(G_{max}\) ≈ 94,000 kPa 就是 Q2 Masing 模型用的值；六個階段的 \(G/G_{max}\)、\(D\) 見 Q1(b)。

用到的觀念

  1. 同一個試體、同一套儀器，\(\beta\) 不變：\(I/I_0\) 不隨應變改變，所以六個階段都是 \(\beta\) = 0.3111。於是 \(V_s \propto f_n\)、\(G \propto f_n^2\)，\(G/G_{max} = (f_n/f_{n,1})^2\)，連 ρ、H 都消掉。大應變時共振柱量到的是該應變振幅下的割線模數（8.3）。
  2. 模數衰減與阻尼曲線（MRD）（8.5）：應變越大，G 越小、D 越大。
  3. 參考應變 \(\gamma_r\)：\(G/G_{max} = 0.5\) 時的應變；雙曲線模型 \(G/G_{max} = 1/(1+\gamma/\gamma_r)\) 中 \(\gamma_r = \tau_{max}/G_{max}\)（8.6）。
  4. 門檻應變（8.5）：低於 \(\gamma_{tl}\) 為線性、G ≈ \(G_{max}\)；高於 \(\gamma_{tv}\) 開始產生永久體積變化，不排水時會累積超額孔隙水壓。

步驟 1：每個階段的 \(V_s\)、G 與 \(G/G_{max}\)

和 (a) 相同：\(V_s = 2\pi f_nH/\beta\)、\(G = \rho V_s^2\)，\(G_{max}\) 取 stage 1 的 93,176 kPa（stage 1 用 (a) 擬合的 108.22 Hz，其餘用 Table 1）。以 stage 6 為例：

\[ V_s = \frac{2\pi \times 60.7 \times 0.100}{0.31105} = 122.6\ \text{m/s}, \qquad G = 1.95 \times 122.6^2 = 29{,}316\ \text{kPa} \] \[ \frac{G}{G_{max}} = \frac{29{,}316}{93{,}176} = 0.315 \quad\text{（捷徑：}(60.7/108.22)^2 = 0.315\text{）} \]

步驟 2：每個階段的阻尼比

同 (a) 的對數遞減法，n = 5。以 stage 6 為例：

\[ \frac{X_1}{X_6} = \frac{70.62}{1.13} = 62.50, \qquad \delta = \frac{\ln 62.50}{5} = \frac{4.135}{5} = 0.827, \qquad D = \frac{0.827}{2\pi} = 13.16\,\% \]

大阻尼時近似式開始有差：精確式 \(\delta/\sqrt{4\pi^2+\delta^2}\) = 13.05 %，差 0.11 個百分點，作圖時看不出來。各階段逐圈比值 \(X_i/X_{i+1}\) 仍相當穩定（stage 6 為 2.27–2.30），所以用頭尾兩點的 δ 和 ln X 迴歸的 δ 幾乎相同（0.8270 vs 0.8271）。

步驟 3：Darendeli (2001) 比較曲線

darendeli_curves.py 用修正雙曲線（γ 以 % 計、σ′m 以 atm 計）：

\[ \gamma_r = (\phi_1 + \phi_2\,PI\,OCR^{\phi_3})\,\sigma_m'^{\,\phi_4} = 0.0352\,\% \quad (PI = 0,\ \sigma'_m = 1\ \text{atm}) \] \[ \frac{G}{G_{max}} = \frac{1}{1 + (\gamma/\gamma_r)^{a}}, \quad a = 0.919 \] \[ D = b\left(\frac{G}{G_{max}}\right)^{0.1} D_{Masing} + D_{min}, \quad b = 0.6329 - 0.0057\ln N = 0.620,\ \ D_{min} = 0.80\,\% \]

以 stage 4（γ = 0.01 %）為例：\((0.01/0.0352)^{0.919} = 0.315\)，\(G/G_{max} = 1/1.315 = 0.761\)；Masing 阻尼（含 a ≠ 1 修正）\(D_{Masing}\) = 5.23 %，\(D = 0.620 \times 0.761^{0.1} \times 5.23 + 0.80 = 3.96\,\%\)。其他階段同法，列在下面答案表的最後兩欄。

步驟 4：估計參考應變 \(\gamma_r\)

方法一：內插。\(G/G_{max} = 0.5\) 落在 stage 5（0.03 %，0.584）與 stage 6（0.1 %，0.315）之間，在 log γ 上線性內插：

\[ \log\gamma_r = \log 0.03 + \frac{0.584 - 0.5}{0.584 - 0.315}\,(\log 0.1 - \log 0.03) = -1.523 + 0.312 \times 0.523 \;\Rightarrow\; \gamma_r = 0.0437\,\% \]

方法二：雙曲線擬合。對六點最小平方擬合 \(1/(1+\gamma/\gamma_r)\)，得 0.0431 %。方法三：修正雙曲線（固定 a = 0.919，與 Darendeli 同形狀），得 0.0441 %。三者相近，取 \(\gamma_r \approx 0.043\%\)。

步驟 5：與門檻應變比較

直接拿各階段的 γ 與 \(\gamma_{tl}\) = 0.001 %、\(\gamma_{tv}\) = 0.01 % 比較，並用量到的 \(G/G_{max}\) 確認：stage 1（0.0005 %）G/Gmax = 1、stage 2（0.001 %）0.987，都還是線性；stage 4（0.01 %）已降到 0.80。

作業：HW3 Q2 Masing 迴圈與阻尼

出處：HW3 Question 2；masing_model_tool.html（演算法重新實作）；學生程式 B1_masing.py、B1_process.xlsx、Masing_tool/masing_gc0.01.csv、masing_gc0.1.csv

題目（改寫）：雙曲線骨架，\(G_{max}\) = 94 000 kPa、\(\gamma_{ref}\) = 0.0004（小數，= 0.04 %），載重路徑 0 → γc → −γc → γc。(a) γc = 0.01 % 與 0.1 % 時畫迴圈，用 \(D = E_D/(4\pi E_{So})\) 算阻尼比，與 Q1 量測值比較。(b) 說明 Masing 阻尼為何在極小應變與大應變都和量測值不同。

解法

  1. 骨架 \(\tau = G_{max}\gamma/(1+|\gamma/\gamma_{ref}|)\)，γ 用小數。反轉點 A：γc = 0.01 % → \(\tau_c = 94\,000 \times 0.0001/1.25 = 7.52\) kPa；0.1 % → \(94\,000 \times 0.001/3.5 = 26.86\) kPa。
  2. 卸載、再載入用 \(\tau = \tau_a + 2f((\gamma-\gamma_a)/2)\)，每段 200 點（與網頁工具相同）。
  3. \(E_D\) = 第 2、3 段（A → B → A）的閉合面積（梯形積分），\(E_{So} = \tfrac12\tau_c\gamma_c\)；能量單位 kPa × 小數應變 = kJ/m³。

梯形積分與封閉解（8.8）差小於 0.001 %；學生下載的網頁 CSV 與重算路徑的 τ 最大差 5 × 10⁻⁷ kPa。

  • (a) 同一條骨架把模數描述得很好（0.800 vs 0.799、0.286 vs 0.315），卻高估阻尼：0.01 % 時高 31 %，0.1 % 時接近量測值的 2 倍。
  • (b) 極小應變：雙曲線趨近直線 \(\tau = G_{max}\gamma\)，卸載與再載入重合，\(D_{Masing} \approx 2x/(3\pi) \to 0\)（0.0005 % 時只有 0.27 %）；但試驗 stage 1 有 1.07 %。這部分阻尼來自顆粒接觸的微滑動與孔隙流體的黏滯，與迴圈的非線性形狀無關，Masing rules 產生不出來。
  • (b) 大應變：Masing 假設反轉曲線是骨架放大 2 倍，迴圈隨 \(\gamma/\gamma_r\) 迅速變胖，上限 \(2/\pi \approx 64\%\)；真實砂土的反轉曲線較「瘦」（顆粒重新排列、剪脹，以及量測中的圈數效應），面積遠小於預測。共振柱自由衰減時振幅一路變小，量到的 \(D\) 也偏向較小應變的值。修正：Darendeli 的 \(b(G/G_{max})^{0.1}\) 縮小大應變段、\(D_{min}\) 補上小應變段，因此 Darendeli 曲線與量測值吻合；非線性程式的 MRDF 等修正也是同樣想法。
小測驗
Gmax = 94 000 kPa、γref = 0.0004。γc = 0.1 % 的迴圈尖端剪應力是多少 kPa？
γc = 0.001；γc/γref = 2.5；τc = 94 000 × 0.001/(1 + 2.5) = 26.86 kPa。若把 γc 寫成 0.1、γref 寫成 0.0004，會得到幾乎等於 τmax = 37.6 kPa 的錯誤值。

作業：HW3 Q3 下孔試驗與等值線性參數

出處：HW3 Question 3；資料 downhole_test.csv；學生程式 C1_downhole.py、C1_process.xlsx；Hardin (1978)

題目（改寫）：三層砂（0–4 m 疏鬆、4–10 m 中等緊密、10–20 m 緊密）位於較硬基盤上，地下水位 1 m，\(\rho\) = 1.95 t/m³、\(K_0\) = 0.5。下孔試驗震源緊鄰鑽孔，路徑視為垂直，量到 2、4、7、10、15、20 m 的 S 波到時。(a) 畫走時–深度，求各層 \(V_s\)、\(G_{max}\)；第 3 層與共振柱（Q1）及 Hardin (1978)（e = 0.70、15 m 處的 \(\sigma'_m\)）比較並討論。(b) 等值線性分析得第 3 層有效應變 0.05 %，用 Q1 的結果估計 G 與 D；這個分析能預測超額孔隙水壓嗎？

解法

  1. 震源在地表，加入原點 (0, 0)。每層用層頂、層內、層底的受波器做直線迴歸 \(t = t_0 + z/V_s\)，斜率倒數即 \(V_s\)；另列相鄰受波器的區間速度作對照。
  2. 15 m 處：\(\sigma_v = 1.95 \times 9.81 \times 15 = 286.9\) kPa、\(u = 9.81 \times 14 = 137.3\) kPa、\(\sigma'_v = 149.6\) kPa、\(\sigma'_m = \tfrac23 \times 149.6 = 99.7\) kPa，與共振柱的壓密應力幾乎相同，兩者可直接比較。
  3. Hardin：\(F(0.70) = 1/(0.3 + 0.343) = 1.555\)；\(G_{max} = 625 \times 1.555 \times \sqrt{101.325 \times 99.7} = 97.7\) MPa（\(p_a\) = 100 kPa 時 97.1 MPa）。
  4. (b)：0.05 % 位於 stage 5（0.03 %）與 stage 6（0.1 %）之間，以 \(\log\gamma\) 內插 \(G/G_{max}\) 與 \(D\)，再乘以現地 \(G_{max}\)。

Q4：隔振墊 SDOF

出處：HW3 Question 4；資料 sdof_frequency_response.csv；學生程式 D1_sdof_isolation.py、D1_process.xlsx；HW3_報告說明.md

對振動敏感的儀器 m = 2,000 kg 放在隔振墊上，視為 SDOF。振動機施加 \(p(t) = p_0\sin\bar\omega t\)、\(p_0 = 0.5\) kN，量 4–12 Hz 的穩態位移振幅（81 點）。這一題與前三題的場址無關。

(a) 隔振墊的性質：\(f_n\)、\(k\)、\(\xi\)、\(c\)

做法：最大點與左右兩點做拋物線內插求峰（\(f_{peak}\)、\(U_{max}\)）。(i) 共振放大法：\(k = m(2\pi f_n)^2\)、\(\rho_s = p_0/k\)、\(D_{max} = U_{max}/\rho_s = 1/(2\xi\sqrt{1-\xi^2})\)，再以 \(f_{peak} = f_n\sqrt{1-2\xi^2}\) 修正 \(f_n\)，兩式疊代到收斂；(ii) 半功率頻寬法：在 \(U_{max}/\sqrt2\) 處線性內插 \(f_1\)、\(f_2\)，\(\xi = (f_2-f_1)/(f_2+f_1)\)。兩法平均作為 (b)、(c) 的採用值。

答：\(f_{peak}\) = 7.97 Hz、\(U_{max}\) = 0.6221 mm。共振放大法 \(f_n\) = 8.019 Hz、\(\xi\) = 7.94 %；半功率法 \(f_1\) = 7.28、\(f_2\) = 8.562 Hz，\(\xi\) = 8.11 %。採用 \(f_n\) = 8.020 Hz、\(\xi\) = 8.02 %、\(k\) = 5,079 kN/m、\(c = 2\xi\sqrt{km}\) = 16.17 kN·s/m。兩法只差約 0.2 %，表示這個隔振墊接近線性的黏滯阻尼系統。

(b) 地板振動傳到儀器

附近施工使地板振動 \(u_g = u_{g0}\sin\bar\omega t\)、\(u_{g0}\) = 0.05 mm。儀器的總位移振幅 \(U_{total} = u_{g0}\,TR_2\)，\(TR_2 = D\sqrt{1+(2\xi\beta)^2}\)（4.10 情況 b）。

\(\rho_d = \rho_sD\)、\(W_D = \pi c\bar\omega\rho_d^2\)、\(W_S = \tfrac12k\rho_d^2\)（4.8）。

答：黏滯阻尼器的比值 \(W_D/(4\pi W_S) = \xi\beta\)，只有在共振時才等於 \(\xi\)。土壤每圈消散的能量來自顆粒接觸面的摩擦（遲滯阻尼），在地震頻率範圍內幾乎與頻率無關，迴圈面積只由應變振幅決定。所以土壤的阻尼比直接用一個迴圈定義 \(\xi = W_D/(4\pi W_S)\)，等於「讓等值的黏滯阻尼器在共振時每圈消散相同能量」，因此不含頻率比（8.4）。
